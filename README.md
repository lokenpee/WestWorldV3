# WestWorldV3

当前应用包版本见[项目清单](package.json)。改动与验证范围见[版本记录](CHANGELOG.md)。

本地小说资产工作台。支持 TXT（小说文本）导入、分章、逐章提取、原文阅读、四类资产人工维护、人物与地点批量合并、整书备份恢复，以及模型配置与连接测试。

## 启动

Windows 下双击 [启动本地服务](scripts/启动本地服务.bat)，服务就绪后自动打开工作台。重复双击会打开已有服务。使用完毕后，双击 [关闭本地服务](scripts/关闭本地服务.bat)。也可以为这两个文件创建桌面快捷方式。

入口固定为下方地址。继续使用原来的浏览器及用户配置，即可读取已保存资料。关闭服务前先结束页面中正在运行的提取或整理任务。

首次使用先安装 Node.js 并执行 `npm install`。命令行启动方式：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

[打开工作台](http://127.0.0.1:5173/)。资料保存在当前浏览器。

## 资产维护

设置好提取模型后，在书籍页点击“开始提取”，按章提取人物、地点和事件节点。每个成功子步骤提交后立即出现在列表，页面分别显示成功、失败与用量。详细步骤见[逐章提取验收](docs/acceptance/extraction.md)。

提取取消、失败或刷新中断后，通过“继续提取”补齐尚未成功的步骤，保留人工修改、合并和删除结果。操作见[提取中断恢复验收](docs/acceptance/extraction-recovery.md)。

选择书籍后，在人物、地点、事件节点和事件线之间切换。可搜索、筛选、新增、编辑和删除。人物层级与事件线状态选择后立即保存。

事件节点通过“涉及人物”搜索和多选人物，姓名、别名和身份均可搜索。资料中找不到的称呼可暂存；同名时选择具体身份。物品、地点及谁对谁做了什么写在概述或详细经过中。

[打开资产验收页](http://127.0.0.1:5173/?acceptance=assets)，点击“装载资产样本”即可操作固定资料。详细步骤见[资产维护验收](docs/acceptance/assets.md)。

## 批量合并

全书提取完成后，“代码整理”先在本地自动合并完整同名档案，剩余异名候选由用户核对，可直接合并或加入队列一键执行；“AI整理”通过Pi核对原文、提交有证据的合并并按需整编资料。两个入口独立运行，报告可刷新后重开。操作见[世界资产整理验收](docs/acceptance/world.md)。

人物或地点列表点击“手动合并”，选择至少两条资料，再预览并选择保留条目和主名。确认后资料、来源及别名合入保留条目；人物关联同步更新，可查看持久合并记录。

[打开合并验收页](http://127.0.0.1:5173/?acceptance=merge)，装载合并样本后选择“渡口人物资料”。详细步骤见[批量合并验收](docs/acceptance/merge.md)。

## 事件线窗口串联

全书逐章提取完成后，点击“串联事件线”。Pi智能体按每100原章、重叠20章处理节点，并复用已有事件线和本书会话。窗口进度、依据与提交确认可展开查看，取消保留已提交结果。操作见[事件线窗口串联验收](docs/acceptance/story.md)。

在事件节点或事件线页签点击“事件网络”，可查看共享节点、孤立节点及事件线，支持搜索、缩放、定位与原资产详情编辑。集中验收见[主线验收清单](docs/acceptance/mainline.md)。

## 备份、恢复与删除

书卡点击“导出”，可下载完整备份或保存到已授权目录。设置页选择备份文件，预检通过后确认恢复为独立副本；原书保留。书卡点击“删除”，可先导出或确认永久删除整书。

[打开备份验收页](http://127.0.0.1:5173/?acceptance=backup)，点击“装载备份样本”。详细步骤见[备份、恢复与整书删除验收](docs/acceptance/backup.md)。

## 模型配置与调用

设置页保存服务商、协议、基础地址、提取模型、整理模型和密钥后，可测试直接生成与智能体基础回复。测试使用已保存配置，显示实际请求次数、耗时、用量与费用状态；等待和请求均可取消。

[打开模型隔离验收页](http://127.0.0.1:5173/?acceptance=models)，点击“填入演示配置”即可操作固定故障场景。真实服务在正常工作台设置页测试。详细步骤见[模型配置与调用验收](docs/acceptance/models.md)。

设置页的“整理工具测试”依次检查人物合并与叙事工作记忆，使用临时样本核对实际读写和提交确认。详见[智能体会话与工具验收](docs/acceptance/agents.md)。

## 检查

跨浏览器备份检查使用 Firefox（浏览器），首次运行浏览器测试前执行 `npx playwright install firefox` 安装测试运行时。

```powershell
npm test
npm run lint
npm run typecheck
npm run test:browser
npm run build
```

浏览器测试使用 Windows 已安装的 Edge（浏览器）。其他系统安装 Chromium（浏览器）后设置 PLAYWRIGHT_CHANNEL（测试浏览器通道）为 chromium。

单元测试覆盖文本、存储、恢复和资产业务；浏览器测试覆盖页面操作、跨标签并发、窄屏与生产构建。
