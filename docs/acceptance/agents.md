# 智能体会话与工具验收

状态：用户已验收通过（2026-10-29）。世界资产与叙事资产两套测试均完成真实读写和提交确认，每套实际请求3次。

在[工作台设置页](http://127.0.0.1:5173/)选择整理模型并保存配置，找到“整理工具测试”。测试会依次运行两套临时样本，使用与业务相同的参数校验、提交确认和 Pi 工具循环。

## 页面操作

1. 点击“测试工具读写”。输入有修改时，按钮显示“保存并测试工具”，先保存当前配置。
2. 查看世界资产测试：读取两个同名人物及原文，执行合并，核对保留人物、来源记录和真实提交确认。
3. 查看叙事资产测试：读取工作记忆，写入固定摘要，核对工作记忆版本与提交确认。
4. 两套均成功后显示“两套工具测试通过”。分别展开“查看提交确认”，检查各自的确认编号。
5. 查看请求次数；正常每套3次。运行时可点击“取消工具测试”，停止当前套并结束余下测试。
6. 回到资产页，确认自己的书籍与资料保留。缩窄到375像素，确认测试按钮、反馈和结果展开入口可操作。

普通文本回复、模型自称成功或虚构的提交编号会显示失败。测试结果说明失败的套件和环节，已发生的临时提交确认可展开查看。

## 固定业务验证

| 用例 | 预期结果 |
| --- | --- |
| 对书A和书B运行独立任务 | 实例、工具范围、会话及消息分别归属本书 |
| 同一本书先运行P3，再运行P2 | 使用不同实例，P2请求保留自己的职责和工具，P3私有消息与工作记忆保持原值 |
| 重建书A运行器并打开原会话 | 保留原会话编号与原始消息，新增记录接到原消息链 |
| 指定其他书籍的会话或仓储 | 返回范围错误 |
| 同一命令键和内容重发 | 返回原确认，资料版本只增长一次 |
| 相同命令键改内容 | 返回命令冲突 |
| 查询后人工更改版本或插入匹配结果 | 写入拒绝，要求重读依据 |
| 同批多个修改中的一个无效 | 全部业务修改和确认共同回滚 |
| 提交成功后工具反馈丢失 | 保留业务修改，按原命令键可取回原确认 |
| 写入后取消或末轮失败 | 保留已提交成果，任务状态列出实际确认 |
| 同批混合写入和最终总结 | 副作用发生前拒绝整个批次 |
| 最终总结虚构修改项或确认编号 | 校验失败，不能记录为完成 |
