# 资产维护验收

状态：资产维护可用。

[打开验收页面](http://127.0.0.1:5173/?acceptance=assets)，点击“装载资产样本”，选择“青石镇来信”。

## 操作检查

| 操作 | 预期结果 |
| --- | --- |
| 新增人物，留空名称后保存 | 名称下显示错误，输入保留 |
| 填人物名称，不选来源章节后保存 | 提示填写来源说明；填写后可保存 |
| 修改人物资料并保存、刷新页面 | 列表和详情显示保存后的值，修订号递增 |
| 修改背景但先改变人物层级 | 层级立即保存，背景输入保留，点击保存后背景生效 |
| 新增地点，选择来源章节并填写描述 | 新地点出现在列表，可搜索、编辑和删除 |
| 新增事件节点，填写章节中不存在的参考引文 | 节点保存成功，显示未定位提示 |
| 将引文改为“船夫沈青在青石码头收到顾衡的来信。” | 选择第一章后保存成功 |
| 新建事件线，勾选节点并保存 | 成员按章节顺序排列，选择“已结束”立即保存 |
| 删除仅属于一条新事件线的唯一节点 | 节点和空事件线一起删除，数量实时更新 |
| 打开“码头收信”节点 | “涉及人物”已选择沈青与顾衡；老沈可搜索到沈青 |
| 搜索人物并勾选，再清空搜索 | 已选人物保留；移除后保存及刷新，选择与事件线人物汇总一致 |
| 已选和待选人物较多时打开“涉及人物” | 已选人物与搜索结果分别逐行展示、限高滚动；搜索、勾选、移除与保存可用 |
| 添加资料中找不到的人物称呼 | 显示待关联提示，保存及刷新后保留；可移除或按身份选择已有资料 |
| 打开含对象人物与物品的节点 | 对象人物进入“涉及人物”，其他对象在详细经过中可见，多次保存保持一份 |
| 删除沈青，再打开“码头收信” | “涉及人物”中移除沈青，保留顾衡；参考引文与章节原文保留 |
| 打开两个浏览器标签页，分别编辑同一人物后先后保存 | 后一页面保留输入并提示重新载入；重新载入后显示先保存页面的资料 |
| 点击“锁定世界资产” | 人物、地点的新增及保存禁用，节点仍可编辑 |
| 点击“锁定叙事资产”，再点击“释放验收锁” | 节点、事件线先锁定，释放后恢复编辑 |
| 切到“山城来客” | 显示该书自己的资产 |
| 缩窄窗口 | 列表与详情上下排列，保存、取消和删除按钮可操作 |
| 在桌面和375像素窗口打开人物编辑，滚动字段区域 | 标题与保存、取消、删除按钮同时可见；短内容与空文本框使用紧凑高度 |
| 查看较多资产，在列表内滚动并缩放窗口 | 资产管理高度适配工作区，类型标签、搜索与合并入口保留，底部条目可滚动到达 |
| 输入较长背景，展开、收起后保存 | 输入内容完整保留，刷新后可再次展开查看 |

人物的搜索与层级筛选可组合使用。关闭详情会放弃未保存输入。重新装载样本会恢复验收资料。

## 自动检查

- 自动化检查覆盖引文降级、人物编号关联、删除同步、合并映射和数据结构。
- 浏览器检查覆盖实际生产构建、跨标签保存、删除确认竞争和窄屏操作。
- 类型检查、静态检查和生产构建通过。
- 已查看桌面和375像素窄屏页面。

## 样本

“青石镇来信”包含船夫沈青、药师陆川、顾衡和掌柜，共4个人物、2个地点、4个节点和2条事件线。老沈记录在沈青的别名中。“山城来客”用于核对跨书隔离。

样本和验收锁使用独立浏览器数据库。正常入口可导入自己的小说并维护四类资产。
