# 备份、恢复与整书删除验收

状态：待用户验收。

[打开备份验收页](http://127.0.0.1:5173/?acceptance=backup)，点击“装载备份样本”，选择“青石镇来信”。正常工作台也可导入自己的小说进行验收。

| 操作 | 预期结果 |
| --- | --- |
| 书卡点击导出，再点击下载备份 | 下载独立备份文件，页面提示已请求下载及文件名 |
| 选择导出目录，再保存到目录 | 文件写入完成后显示目录名与文件名；重复导出生成不同文件 |
| 设置页选择刚导出的备份 | 先显示书名、章节及四类资产数量，确认前书架数量保持原样 |
| 点击确认恢复 | 新增独立书籍并选中，页面仍停留设置；原书保留 |
| 返回资产并打开恢复书籍 | 原文、人物选择、节点、事件线、来源和合并记录完整可查 |
| 重复恢复同一备份 | 再新增一份副本，书名自动区分 |
| 选择损坏、缺文件或校验不符的备份 | 显示具体错误，确认恢复禁用，书架保持原样 |
| 预检后取消 | 清除预览，已有书籍保持原样 |
| 处理任务占用本书时导出 | 可导出一致快照；副本中的运行记录为暂停 |
| 处理任务占用本书时尝试删除 | 提示占用任务并阻止删除，其他书仍可操作 |
| 删除弹窗点击先导出 | 打开同书导出弹窗，导出后由用户重新选择删除 |
| 确认删除一本书 | 目标书从书架移除；另一书的原文、资产与全局设置保留 |
| 删除受其他页面占用后点击重试恢复 | 保留删除待完成提示，解除占用后完成清理 |
| 缩窄为375像素 | 导出、预检、确认、取消和删除按钮可操作 |
