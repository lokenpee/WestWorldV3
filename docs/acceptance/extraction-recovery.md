# 提取中断恢复验收

状态：待用户验收。

在[工作台](http://127.0.0.1:5173/)保存提取模型配置，导入[三章短篇](../../tests/fixtures/A-三章短篇.txt)。样本含序文，共4章／块、8个提取子步骤。

## 取消后继续

1. 点击“开始提取”，等一项人物与地点结果保存后，点击“取消提取”。
2. 查看“已保存”和“待处理”子步骤数量。取消完成后，按钮显示“继续提取”。
3. 修改已保存人物的身份并保存；可手动合并同一人物的两份资料，或删除一条已有地点。
4. 点击“继续提取”。成功步骤保留，只处理缺失步骤。再次查看人工修改、合并目标和删除结果。
5. 完成后刷新，确认成功章节数和用量仍可读取。导出备份，检查预检通过。

## 请求中刷新

1. 开始提取，等至少一个子步骤保存，在下一请求进行时刷新页面。
2. 页面显示已保存数量和“正在确认任务状态”。中断任务的执行权到期后显示“已暂停”和“继续提取”；正常到期等待最多约30秒。
3. 保持页面打开，确认资产数量保持稳定；点击“继续提取”后才开始新的模型请求。
4. 人物与地点已成功、事件节点尚未成功时，从事件节点步骤接着处理。

## 多标签页与失败

| 操作 | 预期结果 |
| --- | --- |
| A页提取期间，在B页打开同一本书 | B页显示正在确认任务状态，启动按钮禁用；A页继续运行 |
| A页取消完成后，在B页点击继续 | B页取得执行权并补缺，已成功步骤保持稳定 |
| 连续点击启动或继续 | 同书只有一个执行者 |
| 子步骤失败后刷新 | 保留失败章节和待处理步骤，可展开查看失败原因 |
| 某章世界资产或叙事资产持续返回错误 | 每项最多3次实际请求，仍失败就保留失败状态并继续下一项，后续章节照常处理 |
| 查看书名下方的章节概览 | 每章左侧分别显示世界资产、叙事资产的提取状态 |
| 全书队列结束后点击一个失败状态块 | 只补提取该章对应的失败子步骤，成功部分及人工修改保留；刷新后重读真实状态 |
| 原标签仍运行，但定时续期延迟超过30秒 | 请求或保存时主动核对并续期，继续全书队列；已被接管时旧任务停止写入 |
| 修正配置后点击继续 | 只重试尚未成功的步骤，成功资产与凭证保留 |
| 删除或合并已提取条目后继续 | 成功步骤继续被认定为已完成，已删除编号保持删除，来源指向保留目标 |
| 运行书A时切到书B，再返回A | 各书进度、结果和执行权分别管理 |
| 在375像素窗口查看恢复状态 | 已保存数量、待处理数量与继续按钮完整可见，详细结果可展开收起 |

全书完成由每章两类成功凭证覆盖确认。资料和来源记录不一致时显示具体错误，保留已有资料供检查或备份恢复。

## 开发检查

业务用例覆盖部分成功后的续跑、人工修改与合并删除保留、失败原因持久化、失效执行权恢复、来源缺失处理，以及旧执行器晚到回复的事务拦截。浏览器用例使用真实模型运行库与固定服务响应，覆盖取消、刷新、跨标签排他执行和开发版、生产版、375像素恢复界面。

针对性检查覆盖两次重试后的失败隔离、两次结构修正成功、执行权过期后的主动续期、单项补提取，以及375像素章节状态布局。检查结果随施工计划登记。
