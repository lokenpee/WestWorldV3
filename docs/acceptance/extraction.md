# 逐章提取验收

## 人物称谓

按[人物别名与通用称谓](../decisions/character-names.md)核对提取结果：稳定别名保留；爸爸、妈妈、姑父、娘娘等通用称谓进入关系或身份说明；“林姑父”等限定称呼可保留。原文只有“太后”而无姓名的人物仍有档案。相同通用称谓的事件人物保持待确认，选择明确人物后保存编号关联。

状态：逐章提取可用。中断后的继续操作见[提取中断恢复验收](extraction-recovery.md)。

在[工作台](http://127.0.0.1:5173/)的设置页保存提取模型和密钥，测试连接成功后进入资产页。

## 固定样本与操作

使用[三章短篇](../../tests/fixtures/A-三章短篇.txt)。样本含一段序文和三章正文，导入后显示4章／块。

1. 选择样本文件，确认分章后点击“仅导入”。
2. 在书籍页点击“开始提取”。查看当前章节、正在处理的人物与地点或事件节点，以及实际请求次数。
3. 人物与地点步骤成功后立即查看资产列表；打开一条资料，修改身份并保存，等待后续章节处理完成。
4. 查看各章两类子步骤的结果、耗时与用量。完成时显示“成功4/4章／块”。模型提取内容以原文核对，数量随实际回复变化。
   提取结束后显示成功与失败数量，点击“查看章节结果”展开逐章明细，再点击“收起章节结果”恢复摘要。
5. 打开事件节点并查看参考引文。引文匹配时自动定位；未匹配时显示回查提示；空引文保留为空。
6. 刷新后查看资产、人工修改、完成状态和最近一次提取用量，再导出备份并检查可正常预检。

## 故障检查

| 操作 | 预期结果 |
| --- | --- |
| 使用错误密钥启动 | 显示鉴权失败；每个子步骤仅请求一次，世界与叙事步骤分别记录结果 |
| 世界步骤失败、叙事步骤成功 | 事件节点保存并出现，章节显示失败，成功凭证保留 |
| 服务暂时故障或结构不符 | 网络重发与一次结构修正共用每子步骤3次实际请求预算 |
| 请求或重试等待时点击“取消提取” | 停止后续请求；已提交资产保留，在途结果结束后释放本书执行权 |
| 提取期间编辑人物 | 可保存人工修改，后续提取保留修改值 |
| 提取期间在另一标签启动同书任务或删除书籍 | 显示本书已有处理任务 |
| 提取期间切换书籍或设置页 | 原书任务继续，结果保存到原书 |
| 缩窄为375像素 | 启动、取消、进度与子步骤结果可操作 |

资产、来源记录、成功凭证与进度在同一事务提交。写入失败时共同回滚；同章同类型只去除完整内容相同的人物或地点，同名不同资料分别保存。

## 开发检查

业务用例覆盖章节顺序、独立请求、即时结果、部分成功、请求预算、原文定位、同书竞争、取消、写入回滚及提取资料备份校验。浏览器用例覆盖开发版与生产版、提取中人工编辑、刷新与375像素布局。

133项单元测试、57项工作台浏览器测试通过；结构化返回约束与用量保存补齐后，4项提取浏览器用例复验通过。严格类型检查、静态检查和生产构建通过，375像素提取面板已查看。

固定响应检查请求与保存流程；真实模型的内容效果由用户按样本原文确认。
