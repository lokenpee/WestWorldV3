# 批量合并验收

状态：待用户验收。

[打开合并验收页面](http://127.0.0.1:5173/?acceptance=merge)，点击“装载合并样本”，选择“渡口人物资料”。

## 样本

张三与张清是同一人在不同章节形成的两份资料，李四是另一人物。合并张三与张清后，人物数量由3变为2。

青石码头与码头是同一地点的两份资料。地点合并后数量由2变为1，描述保留“临河”和“有石阶”。

两个事件节点分别使用人物编号关联，便于检查替换与去重。

## 操作检查

| 操作 | 预期结果 |
| --- | --- |
| 人物列表点击“手动合并” | 出现复选框；少于两项时“确定合并”禁用 |
| 选择张三，搜索张清并选择 | 显示已选2项、含隐藏1项，两个选择都保留 |
| 点击“确定合并” | 预览显示两份资料、来源和修订号 |
| 保留条目选张清，主名选张清 | 显示融合后的身份、外貌、背景、别名和冲突说明 |
| 点击“确认机械合并” | 保留张清编号，人物数量变为2，张三和三哥等称呼进入别名 |
| 打开“交付信件”节点 | “涉及人物”已选择张清、李四，张清只出现一次 |
| 打开合并记录 | 显示3到2的数量变化、原成员、保留编号、别名和来源 |
| 刷新后重新选择该书并查看记录 | 合并结果与记录仍在 |
| 重新装载样本，填写自定义主名后取消预览 | 数据保持原样，已选项保留；退出合并恢复普通列表 |
| 预览打开后，另一浏览器标签页修改张三背景并保存 | 确认合并提示资料已变化；刷新预览后可见新背景，再确认可保留新资料 |
| 预览打开后，另一页面删除一个成员 | 合并被拒绝；取消预览后可清除失效选择 |
| 切到地点并合并青石码头、码头 | 地点数量变为1，描述、别名与两个来源章节保留 |
| 缩窄窗口操作预览 | 内容可滚动，主名选择和确认、取消按钮可用 |

保留条目决定编号，主名决定显示名称，两者可以分别选择。重新装载合并样本会恢复验收资料。

## 自动检查

检查覆盖预览只读、资料融合、人物关联去重、来源链展开、并发冲突、世界域锁、报告保存失败时整体回滚，以及生产构建和窄屏操作。

自动化检查覆盖人物融合、关联替换和持久合并记录；浏览器检查覆盖桌面及375像素窄屏操作，包含生产构建与样本隔离。

合并为本地操作，模型调用次数为0。
