# 模型配置与调用验收

状态：待用户验收。

在工作台打开“设置”，填写自己的服务商、协议、基础地址、提取模型、整理模型和密钥，点击“保存模型配置”。

## 固定演示

[打开隔离验收页](http://127.0.0.1:5173/?acceptance=models)，点击“填入演示配置”，再打开设置。演示服务提供固定响应，配置和凭据保存在独立验收库。

1. 点击“正常回复”，分别测试提取与整理模型，查看回复、用量和一次实际请求。
2. 点击“鉴权失败”后测试，查看一次请求和脱敏错误。
3. 点击“首次服务失败”后测试，查看重发成功和两次请求；“持续服务失败”显示三次请求后结束。
4. 点击“限流等待”后测试，在等待中取消；点击“在途等待”后测试，在请求中取消。
5. 点击“空回复”后测试，查看结果校验错误。

## 真实服务

在[正常工作台](http://127.0.0.1:5173/)进入设置，保存自己的配置和凭据后测试。文本测试走直接调用，整理模型测试走智能体基础回复；请求均经过 Pi 的协议适配器。

基础地址使用服务商提供的接口根地址。Anthropic Messages（消息协议）按 Pi 约定规范化末尾的版本路径。密钥留空会保留该服务商的已存凭据，清除使用独立按钮。

| 操作 | 预期结果 |
| --- | --- |
| 保存配置后刷新，再打开设置 | 配置保留；密钥输入保持空白，状态显示已配置 |
| 修改模型名称但先点击测试 | 本次调用使用已保存的模型；保存后再次测试才使用新模型 |
| 点击测试提取模型 | 显示正常回复、耗时、实际请求次数和用量 |
| 点击测试整理模型 | 通过智能体基础调用得到回复，显示整理模型与执行模式 |
| 拉取模型目录 | 返回可选模型编号，提取与整理模型仍可手工填写 |
| 配置错误密钥后测试 | 显示鉴权错误，仅发起一次请求 |
| 服务短暂失败或限流 | 在总预算内重试，界面显示当前请求与等待状态 |
| 请求中或重试等待中点击取消 | 结束等待及请求，显示已取消，随后可重新测试 |
| 服务返回空文本或异常结果 | 明确显示失败原因 |
| 测试运行时保存另一个模型 | 当前测试继续使用启动时的配置，下次测试使用新配置 |
| 点击清除当前服务商密钥 | 状态更新为未配置；需要凭据的测试提示先保存密钥 |
| 导出书籍备份并查看诊断 | 备份保留书籍资料；密钥留在全局凭据表，诊断使用脱敏文本 |
| 缩窄为375像素 | 配置、保存、测试、取消和结果均可操作 |

直接调用最多三次实际请求，首次、重发和至多一次结果修正共用额度。基础智能体测试最多三次请求、30秒。价格缺少依据时，费用显示为未知。

## 开发检查

125项单元测试、48项浏览器测试通过，严格类型检查、静态检查和生产构建通过。模型专项覆盖三种协议、配置快照、重发与修正共用预算、取消、密钥脱敏及生产页面调用。另核对Pi原生输出能力、测试入口的结束条件，以及原始结构化结果与展示脱敏的分工。桌面和375像素页面已查看。

自动检查以固定服务响应验证真实 SDK（运行库）和浏览器请求路径。真实服务的连通、回复和用量由用户按上表确认。
