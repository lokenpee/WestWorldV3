# 事件网络验收

状态：待用户验收。

打开已包含事件节点和事件线的书籍，进入“事件节点”或“事件线”，点击“事件网络”。

1. 核对节点总数、孤立节点和共享节点。共享节点只显示一次，并标明所属事件线数量。
2. 点击事件线名称，查看对应节点和连线高亮；再次点击或选择“全部事件线”恢复完整显示。
3. 点击节点打开详情，核对名称、概述、来源章节与列表一致。编辑保存后网络同步更新，删除后节点及对应连线消失。
4. 搜索节点名称或编号，筛选章节、只看孤立节点，并使用“定位节点”打开目标。
5. 放大、缩小、查看全图、回到起点及拖动画布，检查布局操作保持资产内容不变。
6. 切换列表与网络，检查搜索和网络选择保留；切书后图和详情归属正确。
7. 在375像素宽度操作筛选、缩放、定位和详情。用方向键移动画布，加减键缩放，回车打开聚焦节点。

固定浏览器样本包含4个节点、2条事件线，其中1个共享节点和1个孤立节点。自动检查覆盖真实资产数量、高亮、搜索、筛选、视图切换、编辑删除、键盘及手机操作。
