## 安装与浏览器兼容说明

- 原 package-lock 含两条无 version 的 oxlint 平台包记录，导致 npm `Invalid Version`。原文件已保留于忽略目录 `node_modules/.cache/stage0/original-package-lock.json`，由 npm 重新生成有效锁文件；对比原本有明确版本的已有包，没有版本变化。
- Vitest 5.0.5、Playwright 1.64.1 为开发依赖，不进入生产包。Pi 是后续运行时依赖，目前仅被隔离测试入口引用，主应用尚未打入。
- Pi 的 provider-env 模块有受 Node 环境分支保护的 `node:fs` 引用，Vite 在探针构建时发出 browser externalization 提示。没有加入 fs polyfill；严格类型与真实浏览器完整探针均通过。此结果不代表所有 Pi Provider 都适用于浏览器，实际服务适配留阶段 6。
- Playwright 的 NO_COLOR/FORCE_COLOR 输出提示只影响终端颜色，不影响测试结果。
