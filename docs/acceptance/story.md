# 叙事整理与会话验收

状态：待用户验收。

打开[跨窗口验收页](http://127.0.0.1:5173/?acceptance=story)，点击“装载跨窗口样本”，选择“跨窗口信件样本”。样本有240原章和6个事件节点，已有逐章提取成功凭证。设置页保存整理模型配置后即可开始串联。

## 窗口与事件线

1. 点击“串联事件线”，查看当前窗口和节点处理数量。
2. 展开“窗口进度与串联依据”，核对三个窗口分别为第1–100、81–180、161–240原章。
3. 查看信件流转的6个节点：接信、交给掌柜、保管、顾衡取信、读信、收回空信封。第81、100、180章的节点会在相邻窗口再次出现，节点编号保持一致。
4. 切到“事件线”查看串联结果。相同信件的连续事件优先追加到已有事件线，成员按章节排序；每个节点的事件线关联与成员表一致。
5. 查看窗口依据和提交确认，再刷新页面。窗口进度、原会话、事件线与确认保持保存。
6. 点击“重新串联事件线”，当前资料与检查点匹配时跳过已完成窗口。人工修改节点或线后，可继续核对当前资料。
7. 导出书籍备份并预检，核对事件线、检查点、原始会话和逐项依据。

原文把6个节点明确写为同一封信的流转，固定服务响应会串成一条包含6个节点的线。真实模型的关联依据和保留疑点应结合原文检查。

## 取消、锁与分页

| 操作 | 预期结果 |
| --- | --- |
| 提取未完成时查看入口 | 提示先完成全书逐章提取，启动保持禁用 |
| 串联运行时修改本书节点或事件线 | 编辑与保存按叙事域锁禁用 |
| 串联运行时查看原文或维护人物、地点 | 查看与世界资产操作可用，实际修改仍遵守世界域锁 |
| 第一窗口提交后，在下一窗口请求中取消 | 已完成窗口和事件线保留，请求停止后释放叙事与会话执行权 |
| 取消后点击“继续串联事件线” | 复用同书会话及窗口内逐项进度，只处理剩余节点和未读目录 |
| 同时在另一标签启动本书串联 | 执行权检查拒绝重复任务 |
| 单窗超过20个节点 | 每批最多20项，全部节点页核对完成后才记录窗口完成 |
| 已有事件线超过50条 | 分页读取目录，首50条提示作为入口；未读目录保留为待处理 |
| 重复提交相同成员集合的创建请求 | 保持一条事件线，已有节点和反向关联稳定 |
| 缩窄为375像素 | 启动、取消、进度和依据展开入口可操作，详细记录在区域内滚动 |

窗口串联完成后显示“窗口串联完成”。全书孤点、事件线和复核事项通过全书复核清单继续处理。

## 全书复核与会话恢复

1. 窗口串联完成后点击“全书复核”，观察孤立节点、事件线和复核事项的清单进度。
2. 完成后显示“全书复核完成”与“待检查 0 项”。展开“窗口进度与串联依据”，核对逐项结论及实际提交确认。合理独立的节点可以继续保持孤立。
3. 点击“查看会话历史”，记下会话编号。切到“山城来客”，再返回“跨窗口信件样本”；刷新页面后重新打开历史，核对原会话编号和记录。
4. 展开“工作记忆与待复核事项”，查看摘要与判断。资料改变后，需要核对的依据显示为已变化。
5. 复核运行时取消，再点击“继续全书复核”。已提交资料与已检查范围保留，剩余项继续处理。

## 上下文压缩

1. 在[独立验收页](http://127.0.0.1:5173/?acceptance=story)完成窗口串联后，点击“装载压缩验收历史”。验收库追加一段长历史，并将整理容量设置为65536。
2. 点击“全书复核”或“继续全书复核”，观察“正在压缩会话上下文…”和压缩前后用量。历史条目总数继续增长，压缩次数增加。
3. 刷新页面，打开会话历史，逐页查看原始任务、模型回复、工具结果、提交确认和压缩摘要。长条目通过上一段、下一段查看完整内容。
4. 取消压缩时，完整原历史与已提交资料保留。继续复核后重新尝试压缩。
5. 将窗口缩为1366×768和375×812，展开历史、记忆和依据。标题与操作按钮保持可见，长内容在卡片内部滚动。

压缩失败、空摘要和压缩后仍超窗时显示错误，保留原历史与继续入口。本轮每项处理一次，未完成项让后续任务继续；本轮结束显示剩余数量，用户点击继续后重试。书籍备份包含原始会话和压缩记录。

## 开发检查

业务检查覆盖100/20窗口边界、原章切块、240章窗口终止、超过100节点的任务划分、超过50条线的目录分页、全书清单按20项分页、合理孤点、未解决和过期事项、检查点复用、叙事编辑锁与备份结构。会话检查覆盖按书隔离、刷新恢复、长历史压缩、工具配对、取消、空摘要、仍超窗、并发末端变化和一次强制压缩恢复。

## 分层读取与跨窗口线索

- 本批输入只包含节点目录和相关资料摘要；长节点减少每批数量，完整经过与引文按需读取。
- 第8章登记旧印章用途疑点，第165章出现印章证明身份：新批次能检索到旧节点、原事项和已有线；查证后沿用原线，原事项更新为已解决。
- 没有证据的疑点继续保持未解决，同物件名称只产生候选关系。
- 长节点详情按字符位置续读，分页拼接能还原完整字段；候选超过一页时可以继续检索。
- 其他书籍及其他会话的事项保持隔离。

## 子任务收尾与失败恢复

按[叙事整理的排队与恢复](../decisions/story-organization.md)核对预算和状态。

- 第15次请求或剩余60秒收到收尾提醒，第20次或目标时间结束后保留在途响应与已提交成果。
- 某组总结失败，具体工具错误和提交编号仍可查看；其他任务继续处理。
- 同窗完成前20个节点后中断，继续只领取剩余节点。
- 后窗给重叠节点增加事件线，前窗保持完成；实际原文或节点内容改变仍需复核。
- 全书复核时浏览目录，其他节点变化不会让无关已核实项回队首。
- 报告逐项显示节点或事件线编号、名称、当前关联及剩余编号，原始会话仍可回查。
