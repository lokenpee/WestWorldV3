# 智能体运行与项目适配

## 背景

世界资产整理和叙事整理需要独立的书籍范围、模型工具调用、消息恢复和业务提交确认。模型调用复用现有配置、凭据及实际请求预算。

## 选定方案

当前行为要求见[智能体会话与工具](../../openspec/specs/agent-session/spec.md)，对应条款 AGENT-RUNTIME-ADAPTATION-01、AGENT-RUNTIME-ADAPTATION-02、AGENT-RUNTIME-ADAPTATION-03、AGENT-RUNTIME-ADAPTATION-04、AGENT-RUNTIME-ADAPTATION-05。


## 替代方案

维护独立的智能体循环会重复消息和工具调度职责，并增加与 Pi 行为同步的工作，因此智能体运行使用包内公开接口。

## 后果

模型协议和智能体生命周期随锁定的 Pi 版本维护，业务规则集中在项目适配层。事务仓储明确处理异步事件与数据库事务上下文，消息追加与会话末端一起保存。

## 跨浏览器仓储事务

读取先收集所需记录，在短事务中核对一致性；资料变化时重新取得快照，指纹等计算在事务外完成。按实际读取范围取得数据，按章查询原文保持指定章节范围。

写入先暂存修改和计算结果，提交事务核对读取版本与执行权，再原子应用。并行变更触发重新读取或冲突反馈，异常保留原数据。相同仓储实例的写操作按顺序提交。
