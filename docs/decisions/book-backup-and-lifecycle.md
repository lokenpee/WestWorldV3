# 完整备份与可恢复的书籍操作

## 背景

每本书的原文、资产、来源和处理记录保存在独立数据库。书架与书库分开保存，恢复与删除需要在浏览器关闭或存储失败后继续完成。

## 选定方案

当前行为要求见[备份与书籍删除](../../openspec/specs/book-backup/spec.md)，对应条款 BOOK-BACKUP-AND-LIFECYCLE-01。


## 替代方案

单份资料 JSON 无法检查章节文件和保留全部记录；覆盖原书会使恢复失败影响原资料。完整快照加独立副本便于核对与重复恢复。

先删除数据库再更新书架，会在失败时留下无法打开的书卡。先登记日志并隐藏入口，让删除进度可以重试。

## 后果与实现

压缩使用规格规定的 fflate（ZIP 压缩库）0.8.3，校验使用浏览器原生加密能力。备份功能集中在现有功能目录，读写复用仓储与生命周期服务，页面沿用现有表单和弹窗样式。

验收覆盖导出再恢复、损坏文件、旧版本迁移、来源与报告、处理期间快照、删除资源竞争、跨标签刷新、阻塞后重试，以及桌面和手机宽度下的操作。
