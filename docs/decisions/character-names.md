# 人物别名与通用称谓

## 背景

亲属称谓、职务和尊称依赖说话者、时间及场景。把这些称谓用于全书名称匹配，会将不同人物的记录和事件错误关联。

## 选定方案

P1记录原文明示属于人物的稳定别名、化名、绰号及指向明确的限定称呼。亲属关系按原文保留在关系字段，通用称谓保留在身份说明。人物说出的称呼归属于被称呼者。

保存与匹配共用称谓规则：已知通用称谓按完整词识别，“林姑父”“宋皇后”等限定称呼保留。原文只提供“太后”等称谓时，人物档案保留原称谓主名，身份和场景提供区分依据。

通用称谓不参与自动人物绑定、名称合并候选和全书名称频次统计。明确的人物编号关联及人工选择继续有效。AI判同仍需核对原文、身份、关系和场景。

旧别名在展示和AI查询时归入“原文称谓”说明；数据库原记录保持可追溯，保存或合并时写入规范化字段。已有事实底稿同步保留称谓说明，供后续整编覆盖。已生成的可疑人物关联结合原文人工复核。

## 替代方案

只修改提示词无法处理旧数据和偶发错误输出；删除全部称谓会丢失只以职务或亲属身份出现的人物。因此同时规范提取、保存与匹配，保留人物及原文信息。

## 后果

通用称谓留下上下文信息，稳定别名用于检索和候选发现。精确词表负责常见情况，提示词处理语境判断；新增语境和称谓通过样本验收完善。
