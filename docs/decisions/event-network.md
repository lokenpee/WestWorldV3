# 事件网络展示

## 背景

节点和事件线需要在列表之外展示章节顺序、共享成员与孤立事件，并与现有编辑入口保持一致。

## 选定方案

网络读取当前书籍的节点、事件线和章节，在节点或事件线列表旁提供视图切换。按章节组织位置，共享节点绘制一次，事件线成员按章节和节点顺序连接。选中事件线高亮其关系，节点详情与编辑复用现有资产编辑器。

采用SVG（矢量图）绘制，并按视口筛选可见节点和连线。缩放、平移、搜索及筛选只改变展示；同书视图状态在当前页面会话中保留。鼠标、触摸和键盘使用同一份资产数据。

## 替代方案

按每条事件线重复绘制节点容易误读共享关系；为图形另建一套业务数据会增加同步成本。因此布局由现有资产派生，修改通过原资产服务完成。

## 后果

图与列表共享版本和编辑锁，保存与删除后同步更新。较大网络通过章节筛选、搜索、定位和视口裁剪操作，备份仍以原资产为准。
