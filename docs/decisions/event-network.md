# 事件网络展示

## 背景

节点和事件线需要在列表之外展示章节顺序、共享成员与孤立事件，并与现有编辑入口保持一致。

## 选定方案

当前行为要求见[事件网络](../../openspec/specs/event-network/spec.md)，对应条款 EVENT-NETWORK-01、EVENT-NETWORK-02。


## 替代方案

按每条事件线重复绘制节点容易误读共享关系；为图形另建一套业务数据会增加同步成本。因此布局由现有资产派生，修改通过原资产服务完成。

## 后果

图与列表共享版本和编辑锁，保存与删除后同步更新。较大网络通过章节筛选、搜索、定位和视口裁剪操作，备份仍以原资产为准。
