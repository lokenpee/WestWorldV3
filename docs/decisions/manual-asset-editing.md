# 人工资产维护

## 背景

人物、地点、事件节点和事件线共用当前资产库。多个浏览器标签页可以同时查看资料，保存和删除需要保持版本及关联一致。

## 选定方案

- 新增、编辑、即时保存和删除共用业务验证与数据库事务。
- 人工资产使用独立编号，记录人工来源。人物、地点可选择来源章节；没有章节时填写来源说明。
- 保存比较表单读取时的修订号。记录变化时保留输入，提示重新载入。
- 人物层级和事件线状态选择后立即保存，其他输入保持原样。
- 四类资产主列表搜索按匹配相关度排列：名称或编号完全匹配、别名完全匹配、名称或编号或别名前缀匹配、部分匹配、正文提及依次排序。名称、编号、别名处于同一匹配等级时按该字段顺序优先；相同等级和字段优先匹配位置靠前、较短的值。随后按名称、同名记录的来源章节顺序及编号稳定排列。
- 搜索保留人物身份、地点描述和节点概述的内容匹配，事件线支持起因、经过与结果；输入统一处理首尾空白、全角字符和大小写。清空搜索后按原名称与编号排列，人物层级筛选和合并选择按稳定编号保留。
- 节点参考引文可为空。匹配时记录位置；未匹配时显示提示并保存。已定位节点按引文顺序排列，其他节点保持稳定顺序。
- 事件线成员按章节与节点顺序排列；成员与节点反向归属同事务更新。删除最后一个成员时删除空线。
- 节点保存稳定人物编号和当前名称。删除人物移除关联；改名同步名称；合并替换为保留人物编号与主名并去重。原文章节和参考引文保留。真实同名人物按身份选择。
- 节点以“涉及人物”统一搜索和多选人物，选择与稳定编号关联同步保存；暂存称呼显示待关联提示。物品、地点及行为方向写入概述或详细经过。已有对象内容在详细经过中呈现，原始对象记录保留。
- 删除记录留下墓碑；被并入目标的来源映射同步标记删除，提取成功凭证保留。
- 世界资产整理持锁时禁止人物、地点人工写入；叙事整理持锁时禁止节点、事件线人工写入。页面与写入事务共同检查。

## 其他方案

只禁用页面按钮无法约束其他标签页。逐条保存关联会留下部分更新，因此采用事务内校验和提交。

## 后果

表单冲突需要重新读取后保存。删除节点会改变相关事件线及资料数量。名称变化会更新人物引用和出场统计，人工层级保持优先。
