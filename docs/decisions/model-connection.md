# 统一模型配置与 Pi 调用

## 背景

提取与整理需要共用服务地址、模型配置、凭据、错误分类和实际请求预算。设置页的连接测试使用与业务相同的模型入口。

## 选定方案

当前行为要求见[模型配置与调用](../../openspec/specs/model-access/spec.md)，对应条款 MODEL-CONNECTION-01。


## 替代方案

直接使用 Pi 的已发布包可以沿用它的协议转换、模型调用和智能体循环。复制源码或维护分支适用于修改库内部行为的需求，会增加版本同步工作。

Pi 两个运行库来自[开源仓库](https://github.com/earendil-works/pi)，采用 MIT（开源许可）。应用通过公开接口传入已保存配置、凭据、取消信号和实际请求统计。

为每个页面分别建立请求代码，会使配置解析、取消与重试计数产生差异，因此调用统一经过模型入口。

## 实现与验收

先验证配置与凭据持久化，再接模型解析和调用，最后接设置表单及浏览器故障用例。模块沿用现有本地存储和表单写法，依赖使用已经安装的 Pi 两个库，按需加载协议代码。

验收检查保存后刷新、未保存输入、运行中改配置、实际请求计数、鉴权失败、限流、取消、空响应、敏感信息脱敏及生产浏览器调用。真实服务的回复与用量由用户在设置页操作确认。
