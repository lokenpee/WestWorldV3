# 阅读入口与统一术语

WestWorld 按书管理小说原文、人物、地点、关系和叙事资料。打开「资产」选择一本书，即可阅读章节、运行提取或整理任务、浏览资产。「设置」管理模型、本机书库与备份。「游玩」显示所选书名，行动框和发送按钮处于禁用状态。

## 当前能力

| 想做什么 | 从哪里进入 | 查阅 |
|---|---|---|
| 导入小说并阅读原文 | 从书架选择 TXT，预览分章并点击「仅导入」。在书籍的「章节概览」点击章名可看全文。 | [产品流程](01-PRD.md) |
| 提取人物、地点、关系和事件节点 | 在「P1 逐章提取全书」启动提取。世界和叙事两路可同时运行，各自按章保存结果。 | [提取与恢复](04-Spec-流程接口与算法.md) |
| 整理世界资产 | 在 P2 区域核对合并候选，或单独运行识别重复人物、优化人物资料、整理人物关系。人物详情也可启动指定人物的任务。 | [工作台操作](06-界面与交互规格.md) |
| 整理和复核事件 | 在「P3 叙事大纲」逐节点串联事件，再按疑似组核对边界、逐件核对经过。已有事件可单独复核。 | [调度与工具](05-Spec-AI与会话.md) |
| 查资产、原文依据和整理结果 | 从人物、地点、节点、事件、故事线标签查看资料。在 P2、P3 整理详情中按人物或任务查请求与结果。 | [运行追溯](08-追溯与验证记录.md) |
| 配置模型、保存和恢复书籍 | 「设置」提供聊天模型、向量模型、重排模型及本机存储入口。书架可导出单书备份，在设置页预检并恢复为独立书籍。 | [模型与存储协议](项目技术说明.md) |

P2 和 P3 大纲主流程要求全书的世界与叙事提取凭据齐全。同一本书一次运行一个处理阶段，P1 内部两路提取共享该阶段。独立事件复核要求本书已有事件并能取得执行权。[启动与恢复场景](07-验收与兼容缺陷.md#2-端到端验收场景)

## 统一术语

游玩方案中的存档、回合、剧情动作链、停笔位置、模型可读资料、执行期限及提交结果，在[游玩产品需求](../../openspec/changes/play-three-agent-mvp/proposal.md#terms)中用同一局的实例定义。

| 术语 | 标识 | 在工作台中的含义 |
|---|---|---|
| 书籍、单书资料 | `bookId` | 一次导入产生一个书籍编号。同一文本可多次导入，各自保存资产、任务和会话。磁盘接口用 `book:<bookId>` 寻址。 |
| 原章、章节块 | `chapterIndex` | 分章后分配的编号。`1.1` 表示原章 1 的第一块，长章各块可分别提取。 |
| 原文 | `chapterTexts` | 按章节编号保存的全文，含首个标题前的序文。 |
| P1 逐章提取 | `worldAssets`、`narrativeAssets` | 世界资产一路提取人物、地点与关系，叙事资产一路提取事件节点。每步成功都保存凭据。 |
| P2 世界资产整理 | `scan`、`profiles`、`relations` | 人物整理的三个独立步骤，分别处理身份识别、人物资料和人物关系。代码整理另有同名合并和候选确认入口。 |
| P3 叙事大纲 | `link_node`、`review_boundaries`、`review_sequence` | 逐节点决定事件归属，再对疑似事件组做宏观分界、对单个事件做微观主审。主流程在故事线整理前暂停。 |
| 事件节点 | `nodes` | 一章中的一段情节，记录发生了什么、涉及的人物和地点、原文位置和章内顺序。 |
| 事件 | `storyEvents` | 围绕同一件事组织的一组节点。事件卡保存概况、进展、遗留问题、线索、状态和成员。 |
| 故事线 / 事件线 | `eventLines` | 用于组织相关情节。事件成员由 `eventIds` 引用，节点成员由 `nodeIds` 标识。 |
| 未归属节点 | unassigned node | 尚未挂入事件的节点。串联任务可记录该节点独立保留的理由。 |
| 章节轴 | chapter timeline | 以原文中的章节和章内位置为序排列节点与连线。 |
| 主名、别名与人物层级 | `name`、`aliases`、`roleWeight` | 人物出场统计使用主名和已核实别名。自动分层按频次计算，保留人工或智能体设置的层级。 |
| 合并事实底稿 | `mergeFacts` | 随合并记录保存的字段事实和来源章节，供整编和复核使用。 |
| 直接模型调用 | direct | 程序向指定模型发送输入、校验返回，并决定是否保存。P1 用 `submit_result` 收集当章结果。 |
| 智能体 | Agent | 在任务允许范围内查询或写入数据，按该任务的确认条件结束。 |
| 会话与工作记忆 | session / memory | 会话保存同书任务的消息。工作记忆保存摘要、判断及依据，供模型继续处理。 |
| 上下文压缩 | compaction | 把较早的会话内容归纳为摘要供模型读取，完整消息保存在本书。 |
| 检查点与回执 | checkpoint / receipt | 检查点记录任务恢复的位置及依据。回执记录已经执行的工具操作和保存结果。 |
| 整书备份 | `.wwv2` | 含清单、单书数据及分章原文的 ZIP 文件。设置和模型密钥保存在本机设置范围。 |

开发任务与复现问题分别从[需求池](../../openspec/需求池.md)和[缺陷池](../../openspec/缺陷池.md)进入，开发约定见[仓库指令](../../AGENTS.md)。
