# 界面与交互规格

应用从「资产」打开。日常操作路径是从书架选书，核对章节与提取进度，在 P2 或 P3 面板启动整理，再到资产列表检查写回结果。模型、磁盘存储和恢复副本的入口在「设置」。[工作台](../../src/features/books/BookOverview.tsx) · [设置页](../../src/features/models/ModelSettings.tsx)

## 资产页布局

桌面资产页左侧为书架，右侧为所选书籍的工作台或导入表单。宽度不超过 767px 时外壳上下排列。长列表、人物编辑页和详情区域按可用高度滚动，编辑区保留主要操作。[应用布局](../../src/App.css) · [资产列表与编辑区](../../src/features/assets/AssetsPanel.css)

## UI-01 顶栏导航和选书

顶栏显示应用版本，以及「资产」「游玩」「设置」三个页面。选择页面仅切换组件。书架读出后，优先显示所选书籍，找不到时选取列表首本。导入成功或恢复备份时，以新编号选择新书。从设置恢复后停留在设置页。书架读取失败时可点击「重新读取书架」。[应用外壳与导航](../../src/App.tsx)

## UI-02 书架、导出与整书删除

书卡显示书名、导入日期、章或切块数，另列人物、地点、节点和事件线数量。点击卡片进入工作台。导入保存期间书架操作暂时禁用，处理中的书籍可以导出一致快照。书卡按本书活动任务禁用删除并显示阻挡原因。[书架](../../src/features/books/Bookshelf.tsx)

| 操作 | 界面反馈和结果 |
|---|---|
| 导出 | 「下载备份」生成单书 `.wwv2`。支持目录句柄时，也可在导出弹窗「保存到目录」，或在设置页预选目录。处理中快照恢复到新书后，原运行保持暂停。 |
| 删除 | 弹窗标出目标书名。可取消、先导出或确认删除整书。「先导出」转到同书导出弹窗。如需删除，须再次进入删除操作。服务提交前复查本书执行权。 |
| 恢复 | 在「设置 → 备份与恢复」选择文件，预检显示书名、资产数和错误位置。校验通过后点击「确认恢复为新书」创建独立副本。 |

导出和删除失败时保留弹窗及错误。提交期间操作按钮暂时禁用。[书籍弹窗](../../src/features/backup/BookDialogs.tsx) · [备份预检与恢复](../../src/features/backup/BackupPanel.tsx)

## UI-03 TXT 导入与分章预览

1. 在书架点「导入小说」，拖入或选择一个 TXT。应用读取编码、按章节正则分割，在预览中展示文件、编码、字节数、字符数和章块数。可分别按 UTF-8 或 GBK 重读。
2. 修改正则后，现有预览标记过期，须重新预览才可提交。预览每页 100 章块，各行可打开该章原文。切换文件或解析失败都会清除先前生成的预览。
3. 点「仅导入」保存并选中新书，再从工作台启动 P1。「导入并开始 P1 提取」在当前导入表单中禁用。[导入表单](../../src/features/import/ImportPanel.tsx) · [导入与分章验收](../acceptance/stage-02.md)

## UI-04 工作台、阶段入口与进度

书名下依次显示章节概览、P1、P2、P3、四项资产计数及五类资产列表。章节列表每页 100 项，标题按钮打开整章原文，世界和叙事两项状态分别显示。单项按钮会提取或重新提取该章对应类别，成功后写入当前书。[工作台](../../src/features/books/BookOverview.tsx) · [章节控件](../../src/features/books/ChapterBrowser.tsx)

| 入口 | 操作与结果 |
|---|---|
| P1 逐章提取全书 | 「一起提取」同时启动世界、叙事两类，各自按章顺序保存。也可独立重提一类。先预览清空范围和阻挡原因，再确认。运行中可暂停，取消后可按凭证补齐未完成步骤。章级结果每页 50 项。[提取面板](../../src/features/extraction/ExtractionPanel.tsx) |
| P2 世界资产整理 | 「代码整理」处理完整同名项并展示待选候选。人工可选择成员和主名，直接确认机械合并或加入待合并队列，再用「一键机械合并」执行。三个人物 AI 步骤独立启动，依次列为「识别重复人物」「优化人物资料」「整理人物关系」，支持暂停、继续和取消。[世界资产面板](../../src/features/world/WorldPanel.tsx) |
| P3 叙事大纲 | 全书 P1 成功凭证齐备、本书没有活动执行权时可「开始整理大纲」。依次处理当前节点、宏观疑似组和每件事件，第一阶段结束后显示已在故事线整理前暂停。已有整理成果、需要从头启动时在副本中重建。[大纲面板](../../src/features/story/NarrativePanel.tsx) |
| P3 独立事件复核 | 有可复核事件且取得本书执行权，可直接点「事件复核」。它在当前书写回两步复核结果，跳过逐节点串联和初始向量准备。暂停后「继续事件复核」续原进度。「取消 P3」结束本书未结束的主流程及独立复核，再点「重新开始事件复核」时从现有事件重新分组。[运行与准入](../../src/features/story/narrativeService.ts) |

P3 在宏观阶段显示已确认的组数，在微观阶段显示已主审件数和总件数。待核实意见、节点独立保留原因、任务参数、用量和会话记录可从本书面板查看。[进度显示](../../src/features/story/NarrativePanel.tsx)

## UI-05 资产列表、增删改查与批量合并

资产标签按「人物、地点、节点、事件、故事线」排列，每个标签显示当前条数。概览卡分别统计人物、地点、节点和事件线。节点、事件、故事线支持综合检索或按具体字段检索，例如从节点找原文引文、从事件找成员节点名、从故事线找成员事件名。切换类型会重置检索字段、关键词及当前选择。节点在无关键词或单字段检索时按章节与章内顺序排列。[资产工作区](../../src/features/assets/AssetsPanel.tsx) · [字段检索](../../src/features/assets/narrativeSearch.ts)

### 新增与详情编辑

| 标签 | 操作与显示 |
|---|---|
| 人物 | 搜姓名或别名、筛层级、自动分层。在人物列表或人物网络中定位条目。编辑资料、层级和人物关系。已有且已保存的人物可单独启动或继续 AI 资料、关系整理。 |
| 地点 | 编辑主名、别名、来源和描述。新增人物或地点时可绑定来源章，无章须填写来源说明。 |
| 节点 | 编辑名称、概述、所属章、引文、经过、涉及人物、地点、线索等。可从表单打开所选章节。引文未定位会提示。人物可按身份区分同名，可保留待关联称呼。已有节点显示其事件与故事线归属。 |
| 事件 | 浏览、检索和阅读。详情显示概况、最新进展、待解决问题、关键线索、状态与所属故事线。成员节点按章排列，点击节点进入节点详情。存在归属依据时可展开查看。事件写回由 P3 处理。 |
| 故事线 | 查看和编辑名称、概况、状态。按事件组织的线可展开每个事件的节点。直接关联节点的线提供成员选择器。可切到事件网络定位相关节点。 |

人物层级、已有线的状态在选择后即时保存，普通字段使用「保存」。有人修改同一条目时，正在编辑的表单会提示重新载入。已并入的条目给出保留条目入口。离开有未保存修改的资产详情时可处理当前输入。[资产表单](../../src/features/assets/AssetEditor.tsx) · [人物关系编辑](../../src/features/assets/RelationEditor.tsx) · [事件详情](../../src/features/story/StoryEventDetails.tsx)

### 人物/地点批量手动合并

在同类资产列表点击「手动合并」，勾选至少两条。预览显示各条的编号、来源和版本，「保留条目」决定保留编号，「合并后主名」独立选择。确认前可调整或取消。提交时复查成员及版本。成功后保留实体承接双方的资料和来源，以原编号仍可追踪去向。[合并预览](../../src/features/assets/MergeDialog.tsx) · [机械合并队列](../decisions/mechanical-merge-queue.md)

### P2 整理详情与合并报告

P2 面板「整理详情」可查看三步任务、选定人物的进度、模型请求和已保存结果。已保存的合并报告可查看目标、去向、成功或失败的组与用量。暂停的步骤可继续。从头重启已有步骤时选择复用已完成结果或全部重新整理。[人物整理进度](../../src/features/world/OrganizationProgress.tsx) · [报告对话框](../../src/features/world/WorldReportDialog.tsx) · [人物整理详情](../../src/features/agents/P2OrganizationPanel.tsx)

## UI-06 事件网络

在「节点」或「故事线」标签中切换「列表」与「事件网络」。网络按章和成员顺序绘制，保留孤立节点，共享节点只画一次。可按名称、概述、编号或人物搜索，通过章节或孤点筛选缩小范围。可缩放、拖动、回到起点、定位选择。聚焦节点时突出所属线，共享节点可选择目标线。列表及网络共用资产详情和未保存输入的离开确认。[事件网络实现](../../src/features/network/EventNetwork.tsx) · [交互验收](../acceptance/network.md)

人物标签另提供「人物网络」，可按姓名或别名找人物并查看关系。[人物网络实现](../../src/features/character-network/CharacterNetwork.tsx)

## UI-07 P3 整理详情与会话记录

在 P3 的「整理详情」可按任务看首包材料、原生工具、各轮实际请求、工具结果与事件改动。「查看逐项复核表」按宏观与微观任务查看结果。回包很短时，从成果面板查看本地记录的新增、改动、删除与成员变化。[P3 整理详情](../../src/features/story/NarrativeExecutionPanel.tsx) · [事件改动记录](../../src/features/story/EventTaskOutcomePanel.tsx)

「查看会话历史」可选择本书会话，按每页 20 条查看原始记录。展开条目可核对编号和内容。超过 12000 字符的条目可逐段翻阅。[会话历史](../../src/features/story/SessionHistory.tsx)

## UI-09 设置页

| 区域 | 操作与反馈 |
|---|---|
| 聊天模型 | 选择服务商和地址，输入密钥，拉取目录。提取和整理模型分别可选或手填。修改后点击「保存并测试」会先保存再测试。高级设置提供服务商标识、协议和整理上下文容量。两种角色各可测试基础连接。 |
| P3 事件检索 | 向量与重排模型各设地址和密钥，分别拉取候选并「测试并保存」。平台目录中类型未标注的模型可输入其完整 ID，须通过本角色实测才能保存。 |
| 整理工具测试 | 顺序运行两个隔离样本，验证人物合并与节点串联的读取、写入和确认。界面显示两套的读写、请求次数和结果，可取消操作。 |
| 磁盘存储 | 磁盘服务启动时可看存储状态、将浏览器书库迁入磁盘、生成本机恢复副本或重新检查。 |
| 备份与恢复 | 导出书架当前选书，选择导出目录，或预检并恢复 `.wwv2` 为新书。 |

聊天密钥留空保留当前服务已存凭据，清除用单独按钮。目录拉取、基础模型测试、检索模型实测和整理工具测试各显示自己的结果。书籍导出排除密钥。[模型设置](../../src/features/models/ModelSettings.tsx) · [检索模型设置](../../src/features/models/RetrievalModelSettings.tsx) · [磁盘存储](../../src/features/local-storage/StoragePanel.tsx) · [备份与恢复](../../src/features/backup/BackupPanel.tsx)

## UI-10 游玩入口

「游玩」显示当前书名或尚未选书的提示。「玩家行动」输入框与「发送」按钮均处于禁用状态。[游玩页面](../../src/App.tsx)

## 状态提示与键盘操作

顶层导航和已选书标记当前项，图中节点支持键盘选择。加载、成功与运行中进度通过状态区展示，错误提供具体原因，有重试入口时可原地重读。需确认的清空、合并、删除均在其对应操作中展示影响。文件写入或删除提交期间防止重复点击。[书架和弹窗](../../src/features/backup/BookDialogs.tsx) · [工作台与网络交互](../../src/features/network/EventNetwork.tsx)

## UI-12 任务恢复与反馈

继续前按书和运行重新核对执行权及已保存进度。P1 可补齐未完成步骤。P2 可继续暂停的具体步骤。P3 的暂停恢复与取消重启走不同入口。设置页工具测试使用临时样本，真实书籍的模型结果与确认记录从书籍工作台查看。[提取与恢复](../../src/features/extraction/recovery.ts) · [P2 步骤](../../src/features/world/WorldPanel.tsx) · [P3 运行](../../src/features/story/narrativeService.ts)
