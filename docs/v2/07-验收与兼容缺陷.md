# 验收场景与复测要点

## 1. 验收口径

用固定模型响应核对程序如何选取输入、调用工具、保存资产和恢复任务。核对人物身份、事件归属或因果关系时，选一份小说副本，将模型结论与对应章节原文逐条核对。记录书籍、章节或资产编号，再记下运行和任务编号，便可从整理详情找到同一次调用。[资产与任务的追溯](08-追溯与验证记录.md)

## 按书会话专项验收

让 A 书运行整理任务，切到 B 书查看工作台，确认书籍、资产、请求和报告均属于 B。切回 A 书后打开原任务，核对消息和已保存的工具结果。暂停并刷新，再继续同一任务，应能从保存的位置接续。打开游玩页时，页面显示所选书名，行动输入和发送按钮禁用。[会话上下文检查](../../tests/session-context.test.ts) · [工作台入口](../../src/App.tsx)

## 3. 复测要点

| 编号 | 样本或操作 | 预期结果 |
|---|---|---|
| BUG-01 | 导入首个章标题前带导言的 TXT | 非空导言作为序文保存。按顺序拼接各章块可还原去掉 BOM、统一换行符后的全文。 |
| BUG-02 | 拖入非 TXT 文件，或连续更换待预览的文件 | 选择和拖放执行相同校验。只展示最后一次有效预览，预览失败时禁用导入。 |
| BUG-03 | 打开已有提取结果的书籍概览 | 概览分别统计人物、地点、事件节点和事件线。事件在独立资产标签中浏览。 |
| BUG-04 | 节点中出现“沈青”，书里有两条同名记录 | 节点按称呼保留全部命中的编号，另存人工指定编号。合并人物后，节点绑定指向保留记录。 |
| BUG-05 | 未配置聊天凭据时测试模型连接 | 页面提示凭据要求，用户可返回设置填写并测试。 |
| BUG-06 | 保存空名称、无效成员，或编辑一条已被他人修改的记录 | 写入服务校验必填字段、引用和修订号。校验失败时保留输入，书内记录保持原值。 |
| BUG-07 | 恢复一个损坏的备份包，或在发布书籍时中断 | 损坏文件在预检阶段报告错误。书籍通过完整性检查后才列入书架，中断的发布按生命周期日志恢复或清理。 |
| BUG-08 | 在两个标签页对同书启动同一任务，或在提交前编辑其输入资产 | 服务核对执行权、读取记录的修订号。过期的执行者或输入不能覆盖已经保存的内容。 |
| BUG-09 | 提取含别名的章节，或保存引文与原文无法精确匹配的节点 | 应用按称呼绑定人物编号。引文的定位状态在节点上可查，未匹配的参考引文可以保存。 |
| BUG-10 | 同书有完整同名组，以及“张三”和“张三丰”两条异名记录 | 完整同名组按机械合并规则处理。异名候选按人工确认或模型证据规则处理，结果可追溯到原人物。 |
| BUG-11 | 只完成部分章节的 P1 提取 | P2 和 P3 大纲主流程等待全书两路凭据齐全。独立事件复核检查本书事件与执行权。 |
| BUG-12 | 选书后进入游玩页 | 页面显示所选书名，行动输入与发送按钮禁用。 |
| BUG-13 | A 书运行期间切换到 B 书 | 显示 B 书的请求、费用和报告，取消操作作用于选定任务。 |
| BUG-14 | 查看缺少定价资料的模型调用 | 费用显示未知。已知金额和估算金额按各自状态显示。 |
| BUG-15 | 在 375px 宽的视口打开长表单和网络图 | 可滚动到保存、取消和阶段入口，网络图可平移。 |
| BUG-16 | 编辑人物层级，同时让另一次保存改变该人物的修订号 | 未编辑的详情随记录刷新，正在编辑的表单保留输入并提示冲突。保存成功后显示返回值。 |
| BUG-17 | 模型请求正在等待重试，此时点击取消 | 等待结束，取消后的请求不会发出，已经确认的业务写入保留。 |
| BUG-18 | 把配置中的数值填写为空、非有限数或超出允许范围 | 校验指出无效字段，配置保持原值。 |
| BUG-19 | 章节元数据存在但正文缺失 | 读原文工具报告缺失章节，提取失败，成功凭据不会写入。 |
| BUG-20 | 下载整书备份或保存到授权目录 | 浏览器下载提示表示下载已触发，下载链接在点击后至少一秒才回收。写入目录时，关闭文件流成功后提示已保存。 |

复现结果按编号记入[缺陷池](../../openspec/缺陷池.md)。各功能的执行命令和测试文件见[验收覆盖矩阵](12-验收执行与覆盖矩阵.md)。
