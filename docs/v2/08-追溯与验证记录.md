# 资产与任务的追溯

核对一条资产时，先选中它所属的书。书籍编号确定数据范围，资产编号定位具体记录。要查它是怎样生成的，再用章节、运行和任务编号找到输入、模型回复和工具回执。

## 从资产查原文

| 要核对的问题 | 从哪里看 | 核对内容 |
|---|---|---|
| 节点中的事发生在哪一章 | 资产工作台的节点详情，以及「章节概览」中的对应章名 | 核对章号、章内顺序、详细经过和引文。引文定位状态区分已匹配、未匹配与空值。 |
| 一个人物称呼对应谁 | 人物详情、节点中的涉及人物 | 按人物编号查看命中记录。同名人物可以有不同编号，人工选择的编号单独保存。 |
| 一条人物关系依据什么 | 人物详情中的人物关系 | 核对双方人物编号、两个方向的关系标签和证据章节。 |
| 一件事件由哪些节点组成 | 「事件」标签中的事件详情 | 按成员编号核对各节点的名称和原文顺序。遇到共享节点，可继续查看该节点所属的其他事件。 |

资产字段和引用关系见[数据与存储](03-Spec-数据与存储.md)。页面分别由[章节概览](../../src/features/books/ChapterBrowser.tsx)、[资产工作台](../../src/features/assets/AssetsPanel.tsx)和[事件详情](../../src/features/story/StoryEventDetails.tsx)呈现。

## 从任务查模型输入和保存结果

| 阶段 | 定位一次任务 | 可以核对的记录 |
|---|---|---|
| P1 逐章提取 | 书籍、章号、世界或叙事子步骤 | 章节概览显示两路状态。提取任务引用当次的正文快照，成功凭据记录该步骤产出的资产。用章号与子步骤核对实际写入。[任务与正文快照](../../src/features/extraction/taskStore.ts) |
| P2 人物整理 | 在整理详情选步骤，再选相应的疑似组或人物 | 核对请求材料、工具调用和返回。人物资料及人物关系可按人物定位，合并结果可从该书的整理报告查阅。[整理详情](../../src/features/agents/P2OrganizationPanel.tsx) |
| P3 叙事大纲 | 在整理详情选节点串联、宏观分界或微观主审任务 | 展开对应请求，查看系统规则、动态资料、工具声明、模型回复与回包。任务成果显示保存的字段、成员和确认结论。[请求详情](../../src/features/story/NarrativeRequest.tsx) · [成果计算](../../src/features/story/eventTaskOutcome.ts) |

例如，要核对事件卡为什么多了一个成员，在整理详情中找到涉及该事件的任务，展开 `edit_events` 回执，查看新增的节点编号，再从事件页打开相应成员核对原文。`confirm` 记录模型对当前任务的结论；宏观确认对应一组事件的比较，微观确认对应某件事件的具体版本。[事件工具与确认契约](11-AI工具返回与回放契约.md)

## 查存储与备份

需要核对磁盘记录时，原文取自 `chapterTexts`，节点取自 `nodes`，事件和故事线分别取自 `storyEvents` 和 `eventLines`。运行、任务及工具回执按各自的标识从本书读取。[书库存储协议](项目技术说明.md#本机存储协议)

核对整书备份时，按清单检查内容与文件校验和。导入会分配新书籍编号，可在副本中用书内的资产编号核对原文、事件成员和任务记录。[备份预检](../../src/features/backup/codec.ts) · [副本编号与引用](../../src/features/backup/rebase.ts)

执行复测可按[验收场景](07-验收与兼容缺陷.md)选择样本，再到[验收覆盖矩阵](12-验收执行与覆盖矩阵.md)查对应测试。
