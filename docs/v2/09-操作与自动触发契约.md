# 工作台操作与自动触发

书架按书籍 ID 切换，运行按书籍 ID 和运行 ID 区分。P1 的世界资产和叙事资产两路可以在同书并行，同书 P2、P3 启动时检查其他活动任务及租约。人工保存资产时，服务在提交事务中复核对应的域锁和修订号。成功提交的资产可立即查看。[字段流转](10-字段级数据流与状态转移.md) / [验收入口](12-验收执行与覆盖矩阵.md)

## 书架与导入

### OP-01 · 切换顶层标签

主导航的资产、游玩、设置切换当前视图。已有资产表单改动时先处理离开提示。切页不取消原书运行。[页面入口](../../src/App.tsx)

### OP-02 · 选择书籍/进入

点击书卡后以目标书 ID 重建工作台，切换章节、阶段卡和当前资产查询。书架或书籍读取失败时显示原因和重读入口。

### OP-03 · 打开导入页

书架选择导入小说，显示分章预览。原书任务继续按自己的书籍 ID 保存。[导入面板](../../src/features/import/ImportPanel.tsx)

### OP-04 · 修改分章正则

编辑章节分隔正则只改变输入值。与已解析预览的 `pattern` 不一致时，面板标记预览过期并禁用导入。

### OP-05 · 应用/恢复默认正则

已选文件后，“应用正则并重新预览”用当前编码重新读取文件。“恢复默认”重置规则，有文件时同时重读。解析期间清除旧预览，失败显示原因。

### OP-06 · 选择或拖放TXT

文件选择与拖放都把全部所选文件交给同一加载器。每次接受一个非空 TXT，自动判定 UTF-8 或 GBK。仅最新一次请求能更新界面。预览每页 100 章或块，可翻页并打开原文。[预览加载](../../src/features/import/previewLoader.ts)

### OP-07 · 按UTF8/GBK重读

有预览且未在读取或保存时，按 UTF-8 或 GBK 重读原文件，使用当前正则重新分章。成功后回到第一页，失败可调整编码或规则后重试。

### OP-08 · 换一个文件

“换一个文件”清除当前文件、预览、原文弹窗及错误，保留正则。下一次选文件时重新识别编码。

### OP-09 · 仅导入

点击“仅导入”后，`importNovel(preview)` 校验预览、分配新 ID，写章节、原文和 P1 初始进度，核对后发布到书架并选中新书。失败清理未发布资料，待清理日志可由恢复入口重试。同名文件可导入为新书。[导入与发布](../../src/lib/storage/importService.ts)

要开始提取，进入新书工作台，在“P1 逐章提取全书”点“一起提取”。导入页的“导入并开始 P1 提取”按钮处于禁用状态。[提取面板](../../src/features/extraction/ExtractionPanel.tsx)

## 资产浏览与编辑

### OP-11 · 切换资产分类

工作台的五个资产栏目是人物、地点、节点、事件和故事线。切换栏目重置检索、分页和选中项。节点、事件、故事线均可按字段检索，事件采用只读详情。人物关系网络、事件网络和会话历史各从所属页面打开。[资产浏览入口](../../src/features/assets/AssetsPanel.tsx)

### OP-12 · 筛选人物层级

人物列表按关键词、层级及分页查询。“人物自动分层”在本书运行本地统计，保留手动指定的层级。层级或搜索变化后返回第一页。[列表查询](../../src/features/assets/assetPage.ts)

### OP-13 · 打开资产详情

工作台按当前书、类别、选中 ID 取详情。可编辑条目载入修订号和表单，事件卡展示概况、最新进展、遗留问题、线索和顺序成员，可展开节点资料。[资产编辑器](../../src/features/assets/AssetEditor.tsx) / [事件详情](../../src/features/story/StoryEventDetails.tsx)

### OP-14 · 编辑表单输入

普通输入保存为本地表单，点击保存时核对必填项、引用、编辑权限和修订号。离开有改动的资产页时可“保存并继续”“放弃并继续”或“取消”。文本推荐长度只用于编辑和提示词说明。

### OP-15 · 保存人物

人物保存主名、别名、来源、身份、年龄文字、外貌、性格、背景、原话等。名称变化会影响出场统计和节点人物关联。人物关系在关系编辑器另行保存。[人物与地点写入](../../src/features/assets/service.ts)

### OP-16 · 保存地点

地点保存名称、别名、描述及来源。保存服务在同书事务中检查世界资产写锁和预期修订号。冲突时编辑器保留输入，提示重新载入。

### OP-17 · 保存事件节点

节点表单提交名称、概述、章节、引文、详细经过、人物、地点、线索、时间及状态变化等字段。引文允许留空，找不到匹配原文时提示未定位。人物选择保存稳定关联，地点和线索可逐行输入。[节点表单](../../src/features/assets/AssetEditor.tsx)

### OP-18 · 保存事件线

故事线详情可编辑标题、概况和成员。直接按节点组织的线可勾选节点，按事件组织的大纲在对应事件内调整其节点，由服务同时核对线内归属、事件修订号和本书节点，再刷新派生关系。[编辑与同步](../../src/features/assets/service.ts)

### OP-19 · 即时改变人物层级

已有人物选层级后立即保存，并标为人工指定。新人物的层级随首次保存提交。保存失败显示原因，保留其他未提交表单输入。

### OP-20 · 即时改变事件线状态

已有故事线选“进行中”或“已结束”后即时写 `lineStatus=open/closed`。新建时随表单提交。事件卡的三种事件状态由事件整理工具维护。[事件字段](项目技术说明.md#编辑操作与字段)

### OP-21 · 批量手动合并与预览确认

在人物或地点列表进入手动合并，至少勾选两条同类记录，预览保留对象与主名，确认后提交 `keepId, canonicalName, expectedRevisions`。任一成员缺失或版本变化即要求重新核对。成功后保留条目累加别名与来源，历史记录可查看。[合并服务](../../src/features/assets/merge.ts)

### OP-22 · 关闭详情

关闭或切换条目前先处理未保存改动。取消离开会留在当前编辑器，放弃后只舍弃尚未提交的输入。

### OP-23 · 删除人物/地点资产

从人物或地点详情点“删除条目”，再在对话框确认删除。服务核对本书、修订号和域锁，写来源生命周期并更新相关联的当前资料。失败显示原因并保留详情。

### OP-24 · 删除节点

节点详情经相同删除确认后，服务在同一事务处理节点、线成员与大纲关联。章节原文及既有 P1 凭证保留。[叙事写入](../../src/features/assets/service.ts)

### OP-25 · 删除事件线

故事线详情经相同确认后删除选中的线，重新计算节点反向归属。成员节点可继续从节点列表读取。

### OP-26 · 展开只读字段/事实/经过

详情按对象展示来源与事实底稿、事件成员和引文等。打开章原文或展开明细只读取本书资料。[原文入口](../../src/features/books/ChapterBrowser.tsx)

### OP-61 · 人工新增四类资产

人物、地点、节点、故事线可从对应栏目新增。新记录先在表单填写来源和必要字段，保存成功时获得 ID 和首个修订号。事件栏目提供浏览与检索，第一阶段事件由 P3 写入。[写入方法](项目技术说明.md#业务服务接口)

## 提取与整理

### OP-27 · 开始或继续全书P1

“一起提取”从成功凭据识别缺口，世界资产和叙事资产两路可并行，每路按章顺序处理。已保存子步骤立即可见。章节行可独立提取或重提该章的一类资料。整类重提先预览清空对象和阻碍，再由用户点“清空并重新提取”。点击暂停保留范围，继续从未完成项恢复。[章节按钮](../../src/features/books/ChapterBrowser.tsx) / [清空范围与控制](../../src/features/extraction/ExtractionPanel.tsx)

### OP-33 · 提取或重提单章

在章节行选择世界资产或叙事资产。服务按 `chapterIndex` 和步骤查询成功凭据：已有凭据则替换该章该类结果，否则补提。两类结果分别反馈。[章节控制](../../src/features/books/ChapterBrowser.tsx)

### OP-28 · 独立启动P2或P3

P2 “代码整理”会先合并符合条件的同名记录，余下的候选可选择主名、确认单组或加入队列。人物识别、资料优化和关系整理由三个独立按钮启动，第一步保存疑似组，由用户处理。重开已做过的步骤可选全部重做或复用，人物详情还能启动单人物资料或关系任务。[P2 工作台](../../src/features/world/WorldPanel.tsx)

P3 主流程要求全书 P1 成功凭据齐全且本书执行权可用。首次按原文顺序逐节点串联，再做宏观分界、微观经过复核。第一阶段完成后停在故事线整理前。已有整理结果且没有可继续的主流程时，启动会先建立清除旧 P3 成果的副本。“事件复核”直接在有事件的当前书上复核，跳过串联和初始向量计算。两种入口分别查看运行和成果。[P3 工作台](../../src/features/story/NarrativePanel.tsx) / [启动检查](../../src/features/story/narrativeService.ts)

### OP-29 · 取消指定阶段

P1 “取消提取”结束本书的两路提取并保留已提交资产。P2 暂停和继续对应人物整理步骤，机械队列按组保存进度。P3 “暂停”保留运行进度，“取消 P3”同时结束本书主流程和独立复核中运行或暂停的进度，保留事件和历史。重新开始独立复核使用新运行、新队列和新会话。

### OP-62 · 查看/关闭合并报告

机械合并与人物整理的运行保存在本书，世界资产整理区可以重开报告与执行详情。报告按运行展示处理结果，关闭只结束查看。人物/地点列表另有手动合并记录。[报告入口](../../src/features/world/WorldPanel.tsx)

## 网络与运行详情

### OP-34 · 图的高亮/全部

在事件网络选中节点，可聚焦所属线并淡化其他线。单线可直接聚焦，多线可点选其一，取消聚焦恢复全图。操作只改变本书的视图选择。

### OP-35 · 图缩放/平移/全图/起点

缩放、平移、全图、起点和键盘操作调整视口。滚轮围绕指针缩放，章节轴、节点及连线同步显示。[事件网络](../../src/features/network)

### OP-60 · 图节点打开详情

事件网络按所在栏目打开节点或关联线详情。多线成员可以选择所属线，孤点可以回到节点查看。切换编辑对象前处理尚未保存的表单。[网络操作](../../src/features/network)

### OP-36 · 选择故事会话

P3 下方点“查看会话历史”，在本书会话下拉框切换。选择会话时记录偏移归零，只读取所选历史。[会话历史](../../src/features/story/SessionHistory.tsx)

### OP-37 · 查看任务与请求

P3 首页分别提供会话历史、疑点清单、“P3 整理详情”和“查看逐项复核表”。整理详情按运行、任务和请求读取记录，切换主流程与独立复核能查看各自进度。[任务与请求详情](../../src/features/story/NarrativeExecutionPanel.tsx)

### OP-38 · 打开逐项复核表

P3 面板的“查看逐项复核表”按运行显示宏观、微观任务的处理结果。首页可展开会话疑点、独立保留依据和待核实事项。

### OP-39 · 历史翻页与长条目分段

本书会话历史每页 20 条，可展开查看原始消息、工具结果、提交确认和压缩记录。长条目每段 12,000 字符。翻页只改变查看的位置。[分页实现](../../src/features/story/SessionHistory.tsx)

## 模型与检索设置

### OP-40 · 编辑模型配置

在设置编辑对话模型的服务、基础地址、密钥、提取/整理模型、协议和整理模型上下文容量。P3 事件检索另有向量和重排两个独立配置。[模型设置](../../src/features/models/ModelSettings.tsx)

### OP-41 · 保存模型配置

保存对话模型配置会校验对应字段并写入全局配置。点击拉取或测试时若表单有改动，界面按动作先保存所需配置并针对该次配置请求。测试可取消。

### OP-42 · 输入/保存Key

输入密钥时保留在表单，随配置保存到服务商对应凭据。已配置的服务可以留空沿用。界面只显示配置状态。[配置及凭据](../../src/features/models/config.ts)

### OP-43 · 清除Key

“清除”删除当前服务商的聊天凭据并刷新配置状态。向量和重排按各自角色、地址管理凭据。

### OP-44 · 拉取模型

聊天模型“拉取模型”读取服务目录，选择提取与整理模型。检索模型另按用途筛选目录，支持选择平台返回的未标注用途的候选。向量和重排均须各自“测试并保存”，成功后替换该角色配置。[检索设置](../../src/features/models/RetrievalModelSettings.tsx)

### OP-45 · 测试提取模型

提取模型连接测试使用提取角色发实际模型请求，展示结果、请求次数或错误。拉取目录成功与模型生成成功分别报告。

### OP-46 · 测试整理模型的工具

整理模型连接测试使用隔离样例，核对资产及叙事工具执行、提交和最终确认，结果显示在设置页。[隔离工具探测](../../src/features/agents/probe.ts)

## 备份、删除与游玩页

### OP-49 · 预览备份文件

选择 .wwv2 文件后，工作线程完成解压、校验及转换，返回预检清单与准备句柄。错误列表显示文件路径和原因。换文件、取消或卸载会释放旧句柄。[备份面板](../../src/features/backup/BackupPanel.tsx)

### OP-50 · 确认/取消备份导入

预检通过后“确认恢复为新书”复用已准备数据，以新 ID 保存并核对，再发布到书架。设置页提示已恢复，返回资产查看副本。取消释放准备结果。落盘失败时可从错误提示重试。

### OP-51 · 从设置导出当前书

设置页“导出当前书籍备份”打开与书架相同的导出对话框，目标是已选书。格式、校验及恢复见[备份数据流](10-字段级数据流与状态转移.md#df-10--备份与恢复)。

### OP-52 · 打开导出/删除弹窗

书架针对单书打开导出或删除对话框。导出允许读取运行中快照，删除最终由服务复核本书占用情况。[书籍操作对话框](../../src/features/backup/BookDialogs.tsx)

### OP-53 · 选择导出目录

在支持目录选择的浏览器中，由用户选择导出目录。界面显示目录名，浏览器保存目录授权句柄。实际写文件时再检查权限。

### OP-54 · 保存到目录

“保存到目录”取已记住的目录或重新选择，授权后导出快照，再写入并关闭文件。错误留在对话框，可重试或下载备份。

### OP-55 · 书架下载备份

“下载备份”读取本书一致快照，核对、编码后向浏览器请求下载。若书籍正在处理，提示“处理中快照”。文件名含书名、时间和随机后缀。

### OP-56 · 删除弹窗先导出

删除对话框的“先导出”切到同一本书的导出对话框。导出完成后若要删除，需再次从书架打开删除入口。

### OP-57 · 确认删除整书

“确认删除整书”先排查本书活动任务，再登记删除并移除书架及该书资料，失败按日志恢复。成功后重新读取书架。单独导出的备份文件仍可用于恢复。[删除与恢复](../../src/lib/storage/importService.ts)

### OP-58 · 取消导出/删除弹窗

导出或删除可在操作开始前点击取消，文件处理时按钮禁用。对话框使用显式操作关闭。

### OP-59 · 查看游玩页

主导航的“游玩”页显示所选书名或“尚未选择书籍”。玩家行动输入框和发送按钮均禁用。[游玩页](../../src/App.tsx)

| 编号 | 触发条件 | 当前结果 |
|---|---|---|
| AUTO-01、02 | 打开应用、书架列表变化或新书发布 | 订阅书架。优先选择刚发布的新书，否则当前选择失效时选列表第一本。无书时展示导入页。 |
| AUTO-03 | 本书相关表提交变化 | `useLiveResult` 按书、表及变更类别重新查询章节、资产、任务和报告。切换视图不会重放业务操作。[查询订阅](../../src/hooks/useLiveResult.ts) |
| AUTO-04、05 | 得失域锁、选中条目变化 | 更新控件可用状态。有未提交输入时保留表单，版本冲突提示重新载入，已并入的条目可转到保留对象。 |
| AUTO-08、09 | 打开设置、备份面板或导出框 | 读取配置状态、模型角色和已有目录授权。正式磁盘模式还可查看存储目录、最近保存及备份时间。[本机书库面板](../../src/features/local-storage/StoragePanel.tsx) |
| AUTO-10 | 保存、导入、导出或删除返回 | 对应操作展示结果或错误。文件下载成功提示表示已请求浏览器下载。 |
| AUTO-11 | 图数据、章节顺序、视口或焦点变化 | 更新章节轴、可见节点和连线。视图操作不改变事件成员。 |
| AUTO-12、13 | 准备模型材料、发生请求或收到工具回复 | 按任务装载系统规则、材料及可用工具，记录会话与请求。写入是否成功以持久回执为准。[工具回放](11-AI工具返回与回放契约.md) |
| AUTO-14 | P3 当前任务确认、复核转回或恢复 | 依据节点位置、事件版本和已保存确认调度下一项，宏观疑似组用尽进入微观，微观可带证据退回宏观。尚有待核实项则暂停。[两步复核](项目技术说明.md#两步事件复核) |
| AUTO-15 | P1 当章子步骤成功 | 提交资产、来源及提取凭据后刷新本书进度和列表。普通人工维护保留已有成功凭据。 |
| AUTO-16 | 当前 P2 面板获知新的 AI 报告 | 打开相应报告。机械合并、人工合并及各次运行亦可从历史入口查看。 |

## AUTO-17 · 生命周期恢复

应用启动时检查未结束的导入和删除。保有有效租约的操作继续由原执行者处理，可接手的 `ready` 导入按已保存内容核对并发布，`preparing/cleanup_pending` 清理未发布资料，`deleting` 完成删除。失败保留日志并提示重试。[生命周期实现](../../src/lib/storage/importService.ts) / [启动反馈](../../src/features/import/ImportRecovery.tsx)

设置页还可“迁移浏览器旧数据”或“立即生成恢复副本”。迁移保留浏览器源数据，磁盘备份状态和重试由本机服务提供。[磁盘存储面板](../../src/features/local-storage/StoragePanel.tsx)
