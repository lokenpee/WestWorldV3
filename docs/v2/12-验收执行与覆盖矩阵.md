# 验收执行与覆盖矩阵

业务逻辑用固定样本核对输入、写入和恢复结果。提取内容、人物关系及事件分界要在小说副本中对照原文判断。

## 从仓库运行检查

| 检查 | 命令 |
|---|---|
| 文档链接、归属和规格结构 | `npm run governance:check`，再运行 `npm run openspec -- validate --all --strict`。 |
| 离线单元与集成回归 | `npm run test:unit`。脚本排除调用真实模型的 `live-*.test.ts`。 |
| P3 串联、复核、候选检索及恢复 | `npm run test:unit -- tests/event-workflow.test.ts tests/event-candidates.test.ts tests/story-reading.test.ts tests/narrative-v4.test.ts`。 |
| 磁盘领域读写 | `npm run test:disk` 使用磁盘适配运行指定领域用例。存储服务专项用 `npm run test:unit -- tests/local-storage-integration.test.ts`，磁盘浏览器场景用 `npm run test:storage-browser`。 |
| 浏览器工作台 | `npm run test:workspace` 按[工作台配置](../../playwright.workspace.config.ts)启动开发与生产预览环境。运行完整浏览器检查用 `npm run test:browser`。 |
| 类型、静态与构建 | `npm run typecheck`、`npm run lint`、`npm run build`。 |

命令在仓库根目录执行。[脚本定义](../../package.json)

## 可复现的备份校验失败

`npm run test:unit -- tests/backup.test.ts -t "副本保留事件进展"` 中的样例直接向书库写入事件 E1。该记录有 `coreClue`，缺少事件表必填的 `clues` 数组。导出在校验 `storyEvents[0]` 时报缺少 `clues`，因此不会生成备份文件。版本 4–15 的备份包导入走按版本转换字段的预检入口。[用例](../../tests/backup.test.ts) / [导出校验和导入转换](../../src/features/backup/codec.ts)
