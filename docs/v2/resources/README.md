# 资源入口

逐文件用途和实际消费者见[文档与资源归属](../文档与资源归属.json)。

- 运行时代码直接导入的提示词、结构及工具定义为运行时权威资源，修改须按对应需求影响测试。
- 其他结构、请求样例和回放按清单的设计参考或历史证据用途读取，当前业务规则从能力规格进入。
- runtime 目录是原项目的历史环境记录，当前依赖及构建配置由仓库根目录维护。
- 历史维护脚本针对原重建资料；当前资料的更新范围按变更任务和权威归属确定。

机器入口见[资源权威映射](v2.2/resource-authority.json)，数据含义见[数据文档](../03-Spec-数据与存储.md)，执行结果见[覆盖索引](../12-验收执行与覆盖矩阵.md)。
