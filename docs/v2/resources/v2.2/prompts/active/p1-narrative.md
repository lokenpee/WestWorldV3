# P1 · 提取叙事事件

## 任务

阅读本章，提取相对完整、可独立回查的事件节点，记录参与人物、起因、经过、结果及新出现的信息。

## 铁律

1. 以本章原文为依据。人物的猜测、传闻、谎言、未经证实的指控，保留说法来源和不确定性。
2. 一个完整事件对应一个节点。同一目标下的连续行动、对话和结果写在一起；独立目标或另一条行动线分别记录。普通章节约2～5条仅作参考，按实际独立事件数提取。
3. 人物身世、外貌等静态资料不单独建事件；与当前事件有关的背景和新信息放入经过或新增信息。例如同一次来访中的开门、见礼、取书和交谈合为一个事件。
4. 如实记录本章的关键进展。主线、支线、伏笔和事件归属由后续整理判断。日常情节符合独立事件条件时也可记录。

## 字段

顶层 `nodes` 必填。本章没有可独立记录的事件时传 `[]`。按事件在章内原文首次出现的顺序提交。程序按数组顺序从 `N001` 分配新提取或重提结果的编号，模型只填写节点内容。

「必填」表示必须提交，表中注明可空时使用指定空值。「选填」在有依据时才填写，缺省直接省略。表内字符数含标点，直接引文选较短的连续片段。

### 事件节点 nodes[]

| 字段 | 填写 | 长度与条数 | 提取内容 |
| --- | --- | --- | --- |
| `name` | 必填 | ≤32 字符 | 客观概括这次行动或进展，保留指控、传闻等尚未证实的性质。 |
| `summary` | 必填 | 1～2 句，≤120 字符 | 交代关键进展，保留明确提出的下一步计划或尚未完成的重要行动。 |
| `process` | 选填 | ≤400 字符 | 起因、连续行动、关键对话和结果。合并附属小动作，保留概述未展开的必要细节。 |
| `actors` | 必填，可为 `[]` | 每项 ≤48 字符，按实际参与者填写 | 使用本章原文称呼。包括行动发起者、对话参与者和直接受影响的人物。只在背景中顺带提到的人、物品和地点省略。 |
| `locationNames` | 选填 | ≤6 项，每项 ≤64 字符 | 行动实际发生的地点，从原文确定到合适精度，如「宁国府」或「宁国府前院厢房」。跨多地按行动顺序填；只在谈话中提到的地点可写进经过。 |
| `clues` | 选填 | ≤2 项，每项 ≤32 字符 | 记录本节点中用于查证、追踪或辨认的具体信息，如「账簿第七页的私印」或「琪官儿出逃后投奔的住处」。无此类信息时省略。单独出现的人名、场地和日常物件不足以构成线索。 |
| `world_delta` | 选填 | ≤5 项，每项 ≤120 字符 | 已发生且后续仍可查的变化。写清对象和结果，如「追回款项已入府库」。计划和商议放入概述或经过。 |
| `new_facts` | 选填 | ≤5 项，每项 ≤120 字符 | 本节点揭示、影响人物或情节理解的信息。转述、传闻、猜测和指控注明说法来源和确定程度；重复信息省略。 |
| `time_text` | 选填 | ≤48 字符 | 原文明示的时间，如「亥时三刻」。 |
| `time_hint` | 选填 | ≤48 字符 | 本次事件发生时的原文相对时间，如「次日」「过了半月」。只在计划里提到的日期写进概述或经过。 |
| `quote` | 必填，可为 `""` | ≤120 字符 | 从本章逐字摘录一段连续原文，支持关键进展。找不到合适片段时提交 `""`。 |
| `offset` | 选填 | 从 0 开始的整数 | 确定时填写引文在本章正文中的字符起点。通常省略，由程序定位引文。 |

## 工具

调用一次 `submit_result` 提交本章全部事件节点。只提交工具声明的字段。

### 示例一 · 查证线索、传闻与已发生变化

> 亥时三刻，宁国府账房里，鸳鸯对贾珩道：「我听凤姐说，赖家拿了公中银子。」贾珩命她封存账簿，明日对照账簿第七页的私印查验。鸳鸯当场给账簿贴上了封条。

提交参数：

```json
{
  "nodes": [
    {
      "name": "贾珩听闻赖家贪墨并封存账簿",
      "summary": "鸳鸯转述凤姐称赖家拿了公中银子。贾珩让人封存账簿，打算次日查验第七页的私印。",
      "process": "鸳鸯转述凤姐的说法后，贾珩命她封存账簿，准备次日对照私印查验。鸳鸯当场贴上封条。",
      "actors": ["鸳鸯", "贾珩"],
      "locationNames": ["宁国府账房"],
      "clues": ["账簿第七页的私印"],
      "world_delta": ["账簿已贴封条。"],
      "new_facts": ["鸳鸯转述凤姐称赖家拿了公中银子，说法尚待查验。"],
      "time_text": "亥时三刻",
      "quote": "贾珩命她封存账簿，明日对照账簿第七页的私印查验。鸳鸯当场给账簿贴上了封条。"
    }
  ]
}
```

私印有明确的查验用途。贴封条已完成，次日查验仍是计划。凤姐的说法写明转述来源，出现在谈话内容里的人也照此保留。

### 示例二 · 独立的日常事件，无需填写线索

> 沈宁在青石镇的驿馆借书。看守取来上册，他翻了两页，选定借它回去读。

提交参数：

```json
{
  "nodes": [
    {
      "name": "沈宁到驿馆借书",
      "summary": "沈宁在驿馆翻看后选定借走上册。",
      "actors": ["沈宁", "看守"],
      "locationNames": ["青石镇的驿馆"],
      "quote": "看守取来上册，他翻了两页，选定借它回去读。"
    }
  ]
}
```

上册是本次借阅物件，原文到选定为止。借书的常规动作合在同一个节点。
