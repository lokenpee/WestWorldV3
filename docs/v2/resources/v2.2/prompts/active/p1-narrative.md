# P1 · 提取叙事事件

## 任务

阅读本章，提取相对完整、可独立续接的事件，记录参与人物、起因、经过、结果及新出现的信息。

## 铁律

1. 以本章原文为依据。人物的猜测、传闻、谎言、未经证实的指控，保留说法来源和不确定性。
2. 一个完整事件对应一个节点。同一目标下的连续行动、对话和结果写在一起；独立目标或另一条行动线分别记录。普通章节约2～5条仅作参考，按实际独立事件数提取。
3. 人物身世、外貌等静态资料不单独建事件；与当前事件有关的背景和新信息放入经过或新增信息。例如同一次来访中的开门、见礼、取书和交谈合为一个事件。
4. 客观记录事件，不判重要性、主线支线、伏笔或事件线归属。原文未写的信息按工具规格留空。

## 字段

### 事件 nodes

| 字段 | 提取内容 |
| --- | --- |
| name | 客观概括本次事件的名称 |
| summary | 一到两句事件概述 |
| process | 起因、连续行动、关键对话和结果，合并附属小动作，保留必要细节 |
| actors | 行动人物，使用本章原文称呼 |
| targets | 行动对象或承受者 |
| locationNames | 行动实际发生的地点。按本章可确定的精度填写，如宁国府、荣庆堂、宁国府前院厢房。确实跨多地时按顺序记录，谈话中提到的其他地点写进经过，无法确定时留空。 |
| world_delta | 事件造成的实际状态变化 |
| new_facts | 本次获知的信息；传闻等保留来源和不确定性 |
| started_actions | 已开始、尚未完成的行动 |
| time_text | 原文明示的时间，如“亥时三刻” |
| time_hint | 原文相对时间，如“次日”“过了半月” |
| quote | 便于回查的原文片段 |
| offset | 引文在正文中的字符起点，从0开始；确定时填写 |
| confidence | 提取置信度 |

## 工具

submit_result：提交本章全部事件提取结果。每次回复调用一次，按工具字段规格填写。
