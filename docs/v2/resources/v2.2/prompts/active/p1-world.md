# P1 · 提取世界资产

## 任务

阅读本章，提取出现或被明确提及的人物、人物关系和地点，整理为人物与地点资料。

## 铁律

1. 以本章原文为依据。缺少依据时省略相应选填字段。
2. 同一人物的不同称呼合为一条，关系目标使用该条主名；真实同名的不同人物按身份分开。
3. 未具名但能明确指向的人物，保留原文称谓，如“太后”“王夫人的父亲”；“有人”“众人”等泛称不作为具体人物。
4. 关系须有依据，包含原文明示的临时同盟、敌对或上下级关系。仅同场、交谈、想起、打量或打算办事不足以建立关系；依据不足时省略该条关系。
5. 关系标签表示双方相对于对方的身份。父亲指向儿子时，正向填「父亲」，反向填「儿子」。相互为朋友时两侧都填「朋友」。

## 字段

顶层 `characters` 和 `locations` 都必填。对应类别无可提取条目时传 `[]`。各类条目按原文实际出现或明确提及的对象提取。

「必填」表示必须提交，文本须有内容。「选填」在有依据时才填写，缺省直接省略。表内字符数含标点，列表长度按每项和条数分别计算。压缩概括时保留原文要点，直接引文选较短的连续片段。

### 人物 characters

| 字段 | 填写 | 长度与条数 | 提取内容 |
| --- | --- | --- | --- |
| `name` | 必填 | ≤48 字符 | 本章主要使用的人物名称。未具名但能明确指代时用原文限定称谓。 |
| `aliases_mentioned` | 选填 | ≤6 项，每项 ≤48 字符 | 原文明示同一人的稳定别名或限定称呼，如「琏二哥哥」。通用称呼、职务和代词各归自身语境。 |
| `identity` | 选填 | ≤80 字符 | 本章明示的身份、职务或归属。 |
| `profile` | 选填 | 填写有依据的子字段 | 有年龄或性别依据时填写；两项缺失时省略整个对象。 |
| `profile.ageText` | 选填 | ≤24 字符 | 保留原文年龄表述，如「十六岁」「十四五岁」「年过三旬」。 |
| `profile.gender` | 选填 | ≤12 字符 | 原文明示的性别。 |
| `appearance` | 选填 | ≤160 字符 | 原文具体描写的外貌、气质、身材，含女性的性相关身体特征。 |
| `personality` | 选填 | ≤100 字符 | 有原文依据的性格特征。优先明确描述或有连续表现支持的特征。 |
| `background` | 选填 | ≤160 字符 | 本章交代的人物出身、来历或经历。 |
| `speech_style_sample` | 选填 | ≤100 字符 | 直接摘录一段本章人物原话，优先选能体现说话方式的片段。 |
| `relations` | 选填 | 按实际有据的关系填写 | 同一关系的多个依据择最能说明双方身份的一处。无确证时省略。 |

### 人物关系 relations[]

每条已提取的关系都必须提交下列五项。

| 字段 | 填写 | 长度 | 提取内容 |
| --- | --- | --- | --- |
| `target` | 必填 | ≤48 字符 | 目标人物在本次 `characters` 中的主名。 |
| `relation_type` | 必填 | ≤40 字符 | 简短的小写英文类型，用下划线分词，如 `parent_child`、`friendship`。 |
| `relation_label` | 必填 | ≤24 字符 | 当前人物相对于目标的身份。 |
| `reverse_label` | 必填 | ≤24 字符 | 目标相对于当前人物的身份。 |
| `quote` | 必填 | ≤120 字符 | 能支持关系及双方身份的本章依据，可直接摘录或准确概括。 |

### 地点 locations

| 字段 | 填写 | 长度 | 提取内容 |
| --- | --- | --- | --- |
| `name` | 必填 | ≤64 字符 | 原文可辨认的地点名称或限定称谓，如「宁国府」「荣庆堂」。只有「那里」等泛称时省略该地点。 |
| `description` | 选填 | ≤120 字符 | 用一句话记录原文提供的地点特点。 |

## 工具

调用一次 `submit_result` 提交本章全部人物和地点。只提交工具声明的字段。

### 示例一 · 有明确身份、别名与关系依据

> 青石镇的驿馆青砖灰瓦。驿丞沈青已年过三旬，镇上常称他沈二。跟进门的是沈青的儿子沈宁。沈青道：「先验印，再收信。」

提交参数：

```json
{
  "characters": [
    {
      "name": "沈青",
      "aliases_mentioned": ["沈二"],
      "identity": "驿丞",
      "profile": { "ageText": "年过三旬" },
      "speech_style_sample": "先验印，再收信。",
      "relations": [
        {
          "target": "沈宁",
          "relation_type": "parent_child",
          "relation_label": "父亲",
          "reverse_label": "儿子",
          "quote": "跟进门的是沈青的儿子沈宁。"
        }
      ]
    },
    { "name": "沈宁" }
  ],
  "locations": [
    { "name": "青石镇" },
    { "name": "青石镇的驿馆", "description": "青砖灰瓦。" }
  ]
}
```

### 示例二 · 仅同场交谈，没有关系和地点依据

> 顾衡碰见沈宁，顺口问了一声可曾用饭。两人答话后各自走开。

提交参数：

```json
{ "characters": [{ "name": "顾衡" }, { "name": "沈宁" }], "locations": [] }
```

一次问候不足以判断两人是朋友，也不足以判断年龄或性格。
