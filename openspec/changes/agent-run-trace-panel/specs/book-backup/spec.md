## ADDED Requirements

### Requirement: TRACE-BACKUP-01 运行过程日志备份
系统 SHALL 在备份格式11保留运行过程日志、不可变提示词/工具快照、请求输入引用、工具过程和修改结果；读取继续支持格式4–10；恢复副本重新归属本书，排除凭据和活动租约，旧格式缺少日志时明确标注。

#### Scenario: 过程日志往返
- **WHEN** 含有运行日志的书导出并在新副本恢复
- **THEN** 会话、requestId、输入引用、工具记录和修改结果可查；日志归属新书，API Key、认证头和租约不进入备份。

#### Scenario: 格式兼容
- **WHEN** 新应用读取格式4–10，或旧应用读取格式11
- **THEN** 新应用保留旧格式的资产和报告，运行详情对缺失日志显示“历史明细不完整”；旧应用明确拒绝更新的格式，不误读。

#### Scenario: 一致性导出与引用校验
- **WHEN** 导出时 writer 队列仍有记录，或恢复时 snapshotId、entryId、工具结果引用缺失
- **THEN** 导出前 flush 并暂停新日志，取同一读事务的一致快照，不导出半批记录；恢复逐项校验引用，缺失或哈希不符只标不完整，不用当前数据替代。

#### Scenario: 旧格式
- **WHEN** 恢复格式4–10且不含过程日志的备份
- **THEN** 资产和报告保持；运行详情显示“历史明细不完整”，不伪造输入或工具记录，不读取当前提示词或工具定义冒充历史。
