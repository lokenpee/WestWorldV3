## ADDED Requirements

### Requirement: STORY-TRACE-01 P3 运行详情
系统 SHALL 在 P3 叙事整理提供同一运行详情入口，按窗口/复核、会话和请求展示实际输入、思考、工具过程和事件线修改，不改变现有持续会话和复核行为。

#### Scenario: P3 窗口和复核
- **WHEN** 用户运行窗口串联或全书复核
- **THEN** 运行详情显示窗口范围、会话、请求、事件线工具参数与结果、压缩状态和实际事件线修改；P2 运行不出现在 P3 日志中。

#### Scenario: P3 刷新
- **WHEN** P3 运行中关闭详情或刷新
- **THEN** Agent 继续；已保存请求可查，进行中部分有明确提示，不重放工具或改变事件线。
