## ADDED Requirements

### Requirement: WORLD-ORGANIZATION-TRACE-01 运行详情与修改结果
系统 SHALL 在 P2 世界整理提供运行详情入口，按会话、工作上下文、人物和请求展示实时过程、实际模型输入及数据库实际修改；完成判断继续以工具提交和资产写入为准。

#### Scenario: 查看一次人物处理
- **WHEN** Agent 处理贾政并提交 done=true
- **THEN** 面板显示本次会话/contextId/人物/请求序号、思考（如有）、工具参数和结果、输入资料，以及贾政实际字段前后值和 commitId；不以模型正文声称完成。

#### Scenario: 关闭面板与切换人物
- **WHEN** 用户关闭运行详情或 Agent 切换到下一人物
- **THEN** 关闭不停止运行；下一人物使用新的上下文/请求分组，不把上一人物输入或工具结果混入当前显示。

#### Scenario: 现有入口与配额不变
- **WHEN** 使用运行详情
- **THEN** 不新增聊天输入、固定请求/token 上限、阅读证明或模型结束总结；现有 AI 整理、继续、取消和报告入口保持。
