## ADDED Requirements

### Requirement: BACKUP-PAIR-EDIT-01 人物对编辑结果兼容
系统 SHALL 以数据库版本7与备份格式7保存人物对编辑结果、删除状态、AI修改报告及新增字段枚举；6版书库原子升级，格式4/5/6备份转换为7。格式7恢复 SHALL 保留有效关系与原始依据的区别。

#### Scenario: A19 升级与往返
- **WHEN** 升级含多目标原关系的6版书库，编辑和删除人物对后导出7并恢复为新书
- **THEN** 升级前后原关系等价；恢复后人工修改、删除和AI恢复状态一致，其他同名目标未变化；副本归属独立，不携带本机网络视角。

#### Scenario: A19 非法表与失败
- **WHEN** 预检含跨书端点、重复pairKey或非法状态标签的备份，或升级中断
- **THEN** 明确拒绝非法数据，原书与原文件保持完整；deleted行不被忽略或转换成原始自动连接。
