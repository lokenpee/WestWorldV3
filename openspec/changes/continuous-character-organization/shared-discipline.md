# 所有模型任务共用文学资料处理说明

## 确认与范围

2026-11-13用户要求“文学资料处理说明，可以统一放进discipline，后续和所有任务一起作为system prompt的末尾一起发送”。沿用REQ-019，按跨任务提示词调整的大型变更实施，授权范围包含P1/P2/P3、压缩、旧资料复核和探测的生成请求。

固定说明唯一正文继续放在output-discipline.txt；内容说明小说资料处理目的、事实忠实性、允许语义归并与精简、不因题材篡改人物和事件、不扩写不存在的信息。公共说明不再禁止普通说明或要求隐藏拒绝话语；输出形式、工具和字段要求由各任务规定，保留用户此前要求的工具外说明能力。

字段变化：无存储或API字段新增。现有systemPrompt或system消息正文在发送前追加公共说明；请求观测捕获追加后的内容。原上下文不原地修改，重复应用时移除相同公共正文后在系统提示末尾保留一份，工具定义与user/assistant/tool数据不改动。

数据流：业务正文和动态任务信息 → 模型网关runTurn → 统一追加公共说明 → trace记录 → Provider适配器发送。direct修正、Agent每轮及上下文恢复重新经过相同入口。例：业务正文“整理当前人物”发送为“整理当前人物\n\n【文学资料处理说明】…”；第二次请求仍只有一份说明。

取消、重试、工具权限、落库与备份结构无变化。请求说明新增可能影响实际模型输出，固定响应只能验证组装与链路；用户副本验收核对文学处理效果。
