## 3. 单会话三步编排

- [x] 3.1 新建 `character_organization_v1` 编排模块，启动时创建 run/session 和 `scanIds` 快照，按 `scan → resolve → profiles → relations → finalize → done` 推进；步骤只表示工作重点，不限制工具。检查 C06、C14。
- [x] 3.2 第一步：分页读取100人三字段目录，登记页状态；模型保存/补充跨批疑似组；全部目录确认后才逐组读取完整资料；资料充分直接合并，不确定查原文；组结论写报告，未决组不合并。检查 C01–C04。
- [x] 3.3 第一步收尾：调用 `clear_candidate_groups` 只清本轮活动工作集，保留 `candidateDecisions` 报告；有未处理组时返回编号，不清空；清空失败重试不重复合并。检查 C05。
- [x] 3.4 第二步：按合并后当前有效人物逐个检查非关系资料；允许读取完整资产、事实底稿、原文和其他资产；归纳重复、修正矛盾、保留独有事实；无变化只记录 no_change；不另起独立复核模型。检查 C09、C10。

- [x] 3.6 收尾：重新统计人物和地点出场频次，保留 manual/agent 的 `roleWeight`；统计成功后才标 completed；失败保留 `statisticsPending`，继续只收尾。检查 C10、C16。
- [x] 3.7 续做与新轮：暂停/取消/失败后同 run/session 续未完成项；整轮完成后再次启动创建新 run/session，重新全量扫描当前人物，无变化不写资产。检查 C15、C17。
