## ADDED Requirements

### Requirement: STORY-TRACE-02 P3 单一入口与持续会话
系统 SHALL 在 P3 只提供一个“整理详情”入口，按一个持续会话的请求顺序展示，不套用 P2 的逐人物窗口；修改结果和用量与同一运行关联。

#### Scenario: P3 连续请求
- **WHEN** P3 在同一会话中发出多次请求
- **THEN** 运行过程按请求顺序展示，不按人物拆分；每条请求只显示自己的工具、输入和结果。

#### Scenario: P3 单一入口
- **WHEN** 用户要查看用量或运行过程
- **THEN** 外部只有一个“整理详情”，内部提供运行过程、修改结果和用量。
