## ADDED Requirements

### Requirement: WORLD-ORGANIZATION-TRACE-02 整理详情单一入口与人物窗口
系统 SHALL 在 P2 只提供一个“整理详情”入口，内部按阶段、人物/工作上下文和请求展示；修改结果只列实际写库资产修改，提交工具参数不得冒充已保存修改。

#### Scenario: 切换人物窗口
- **WHEN** 同一轮整理连续处理多个人物
- **THEN** 用户可按人物/工作窗口切换；人物窗口内可再切换资料/关系上下文；每个上下文只显示该人物该阶段的回合；目录、候选不混入人物窗口；标题优先显示姓名，内部编号在回合信息。

#### Scenario: 修改结果
- **WHEN** 某人物既有 changed 又有 no_change，且提交工具返回成功
- **THEN** 修改结果按实际 assetEdits 展示字段、修改前、修改后、理由、commitId 和保存状态；提交工具参数放在单列的“提交记录”中。

#### Scenario: 单一入口
- **WHEN** 用户要查看整理报告、用量或运行过程
- **THEN** 外部只有一个“整理详情”；运行过程、修改结果、用量在内部切换，报告可从内部打开。
