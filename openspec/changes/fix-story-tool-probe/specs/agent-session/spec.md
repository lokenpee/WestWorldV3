## ADDED Requirements

### Requirement: STORY-PROBE-01 叙事探针按步骤提供工具

设置页叙事工具测试 SHALL 按已成功的实际读取、写入和提交确认依次提供当前工具。每套沿用三次实际请求和三十秒上限，使用一次性样本。

#### Scenario: 按当前步骤提供工具

- **WHEN** 模型运行叙事工具测试并按要求成功执行每一步
- **THEN** 三次请求分别提供读取工作记忆、写入工作记忆和总结工具，提交确认与实际写入一致。

#### Scenario: 读取失败耗尽请求

- **WHEN** 模型在请求上限内仍未成功读取工作记忆
- **THEN** 设置页显示读取环节未完成，并报告可用的工具错误或未发出调用的情况，测试保持失败。
