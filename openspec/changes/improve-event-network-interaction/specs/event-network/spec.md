## ADDED Requirements

### Requirement: NODE-FOCUS-01 按节点浏览所属事件线
系统 SHALL 支持以鼠标位置为中心的滑轮缩放，保留拖动、按钮和键盘；移除全书事件线选择栏，通过节点选择突出所属事件线。编辑对象 SHALL 跟随当前栏目，并沿用未保存修改提醒。

#### Scenario: 鼠标缩放
- **WHEN** 用户在画布上滚动滑轮
- **THEN** 鼠标指向的图坐标保持位置，网络缩放而页面不滚动，资产数据不变。

#### Scenario: 单线与孤立节点
- **WHEN** 点击只属于一条线或未归线的节点
- **THEN** 节点栏目编辑节点；事件线栏目编辑所属线，未归线显示提示；所属线突出，其他线变淡，可取消聚焦。

#### Scenario: 共享节点
- **WHEN** 点击属于多条线的节点
- **THEN** 沿用包含该节点的当前聚焦线，否则突出节点所属线并只列这些线供选择；节点栏目仍编辑该节点，事件线栏目选择后编辑线。

#### Scenario: 未保存切换
- **WHEN** 选择另一个节点或所属线而当前编辑器有未保存修改
- **THEN** 保存或放弃后切换；取消则保留原编辑对象及聚焦。
