# 实施设计

## 字段变化
第1项不改字段及持久格式；ChapterDraft仍包含编号、名称、order、charCount和text，字符数仍按UTF-16。旧书不重切；新导入和用户重做预览采用新算法。第2至21项沿审查所列模块逐项实施，涉及任务记录、查询协议和存储索引时，在该项开始前补充具体字段及兼容方案。

## 数据流转
量化脚本从固定样本调用当前代码，输出JSON指标 → 保存优化前结果 → 修改当前项 → 相同脚本/样本输出优化后结果 → 对比并回归 → 有收益才提交。结果文件放本变更evidence目录；运行中数据库只放系统临时目录。

第1项：TXT规范化正文 → splitChapters识别章节 → splitCharacters在上限附近寻找自然边界 → 原字段生成预览 → 原导入事务保存。长章最大10000，无标题最大4000，无重叠、无吞字。例：旧分块把贾蓉拆为“贾/蓉”；新分块在附近句末或换行处结束，仍拼回全部原文。

## 触发逻辑
用户生成预览时使用新切分；取消、更换文件仍由既有Worker与请求身份处理。不重写已有书、不自动提取、不新增模型调用。算法在上限尾部10%且最多1000字符内寻找末个换行，再找句末及闭引号；余量不足以保持当前块数时使用原硬边界；始终避免拆UTF-16代理对。

## 逐项指标与顺序
每项均先记录基线，后做同样本对比及相关回归。顺序与审查编号一致。

| 项 | 主指标 | 必须同时保持 |
|---|---|---|
| 1 | 固定语义边界样本的断词/断句数 | 全文相等、长度上限、块数、耗时 |
| 2 | 预览挂载行数、复制正文字符数 | 全章节可访问、导入一致 |
| 3 | 同文件解压/解析次数、主线程阻塞 | 校验、换文件失效、发布完整 |
| 4 | 各任务保存字节数/主记录体积 | 任务历史、恢复、备份兼容 |
| 5 | 新增人物时扫描/绑定节点数 | 未绑定和歧义都正确更新 |
| 6 | 单章重提正文读取次数 | 新名称全书统计、人工层级 |
| 7 | 成功关系提交后复用数 | 修改后失效、疑点不跳过 |
| 8 | 冲突解除后重试成功数 | 无越权释放、错误可见 |
| 9 | 同批关系全图构建次数 | 每对使用最新修订指纹 |
| 10 | 单人物完成后读取历史范围 | 最新详情覆盖、快照引用完整 |
| 11 | 进度刷新全表/原文读取数 | 内容变更正确失效 |
| 12 | 长线场景返回相关候选数及Token | 可查完整成员、续接可达 |
| 13 | 详情首次及刷新字节数 | 消息配对、完整历史、累计用量 |
| 14 | 请求准备观测日志读取次数 | 业务上下文不变、日志可查 |
| 15 | 同内容压缩分块及请求数 | 窗口余量、摘要恢复 |
| 16 | 无关写入触发查询数 | 跨窗口和断线恢复 |
| 17 | count/bulk存储调用数与字节数 | 事务待提交视图、顺序和缺项 |
| 18 | 同次配置读取解密数、服务阻塞 | 加密持久化、更新删除失效 |
| 19 | 各栏目读取表数/字节数 | 编辑依赖、筛选和网络完整 |
| 20 | 主线程相似度计算次数及耗时 | 候选集合相等、取消及身份 |
| 21 | low参数命中率、截断识别率和恢复次数 | 原生思考可见、已提交结果保留 |
