## ADDED Requirements

### Requirement: REASONING-RECOVERY 纯思考截断恢复
系统 SHALL 保留纯思考截断回复及其用量，在一次针对性续做后仍无成功工具进展且再次纯思考截断时保存当前工作并暂停。

#### Scenario: 截断后正常完成
- **WHEN** 只返回思考且输出额度用尽，续做时成功调用完成工具
- **THEN** 正常结束，两个回复及用量均保留。

#### Scenario: 连续无行动截断
- **WHEN** 两次纯思考截断之间没有成功工具执行
- **THEN** 暂停原因可见，P2当前人物或P3当前页以及已有提交保留，用户继续可以处理同一工作。

#### Scenario: 不误判正常说明和工具
- **WHEN** 回复含正常正文、工具调用或不是输出额度截断
- **THEN** 保持原有处理，不能套用纯思考续做次数。
