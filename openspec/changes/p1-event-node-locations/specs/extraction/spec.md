## ADDED Requirements

### Requirement: P1-NODE-LOCATION-01 事件节点地点

系统 SHALL 在 P1 叙事提取时允许为事件节点记录行动实际发生的地点，按原文及同一场景上下文能确定的精度填写。场景跨多个地点时保存各地点，无法确定时允许留空。地点随节点保存，并在现有节点详情提供查看和更正。

#### Scenario: 原文提供具体地点

- **WHEN** 正文写明赖大在宁国府前院的一间厢房被拿下，且节点描述的是该行动
- **THEN** 节点地点保留可确定的府、前院及厢房信息，并在保存后可从详情查看。

#### Scenario: 原文只提供大致地点

- **WHEN** 上下文只能确定行动发生在皇宫或宁国府
- **THEN** 地点记录为对应的皇宫或宁国府，精度保持在原文可确认的范围。

#### Scenario: 谈话提到其他地点

- **WHEN** 第145章的节点记录贾珩在荣庆堂谈到去翠华山前查阅东府账簿
- **THEN** 该谈话节点地点显示荣庆堂，谈话内容可继续提及翠华山。

#### Scenario: 多处地点与缺省兼容

- **WHEN** 连续行动跨多个确定地点，或者新提取及旧节点缺少地点
- **THEN** 前者保存按出现顺序去重的地点，后者按无地点读写和展示，节点其余内容可以正常查看和编辑。

#### Scenario: 更正和备份恢复

- **WHEN** 用户在节点详情更正地点并完成整书备份，再恢复到独立副本
- **THEN** 副本节点显示更正后的地点。保存失败时原节点仍可读取，取消后可沿原任务恢复。
