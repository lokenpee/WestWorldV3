# P2 三步独立运行、暂停继续与彻底取消

关联需求 [REQ-022](../../需求池.md)。代码实施和自动检查已完成；剩余边界用例与用户自测待进行。

- [提案](proposal.md)：现状、确认行为、暂停/取消/统计边界和数据流。
- [设计](design.md)：单步调度、运行状态机、runtime 安全边界、按钮和刷新恢复。
- [任务](tasks.md)：实施顺序、模块和检查方法。
- [验收](acceptance.md)：场景、当前核对和实际记录。
- 差异规格：[世界整理](specs/world-organization/spec.md)、[Agent 会话](specs/agent-session/spec.md)。
