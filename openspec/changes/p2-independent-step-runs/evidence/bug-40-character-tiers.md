# BUG-40 人物自动分层实现与检查

## 结果

2026-11-12，按[用户确认方案](../statistics-followup.md)实施。

- 人物列表按钮顺序为层级筛选、人物自动分层、新增人物；P2旧按钮移除。范围为全书人物，不随当前筛选缩小。
- 新入口独立取得本书world租约，复用统计计算/保存，不再读取或接管旧Agent会话。已完成/暂停历史保持，未运行过P2和未配置模型的书也可执行。
- 人工及agent来源层级保留，频次照常更新；自动来源按原分位算法计算，地点频次继续更新。
- 计算期间按章节让出主线程，保存时核全部人物/地点集合与版本，统一事务写入；重入和其他任务被阻止，结束只释放自己的锁。
- 界面显示进行中、处理/调整/保留人数及失败原因；失败可重试，空书显示无人物提示。

## 根因修复位置

原updateOrganizationStatistics只取得新world锁，但finalizeStatistics检查旧session.leaseOwner，导致正常完成后的历史会话也必然不匹配。新statistics模块将计算/保存与Agent收尾分开；旧finalizeStatistics继续维护其原运行，新按钮只执行本地统计。

原异常路径无条件删除world锁也已移除。独立操作仅在确实取得锁、且owner和runId仍属于本次时释放，拒绝并发或失去执行权不会删掉别人的锁。
