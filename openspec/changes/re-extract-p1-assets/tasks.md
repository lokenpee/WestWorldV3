# 实施任务

关联需求 REQ-018。先读[提案](proposal.md)、[设计](design.md)和[提取差异规格](specs/extraction/spec.md)。当前为待审核材料，未开始实施。

## 1. 重提服务与范围

- [x] 1.1 在 `storage.schema.json`、提取进度类型和备份校验中增加 `compileProgress.reExtract` 可选字段；旧数据缺省按普通提取处理。依赖：提案确认。
- [x] 1.2 在 `src/features/extraction/service.ts` 增加 `reExtractPreview`、`reExtract` 和 `continueReExtract`，支持整书/单章 × 世界/叙事；普通 `start`/`retry` 保持只补缺口。检查 E12、E13。
- [x] 1.3 执行前校验成功凭证、模型配置、章节原文、活动任务和已有待继续重提；不满足时不清空。检查 E09。
- [x] 1.4 清空时写入 `reExtract`；继续时只处理该范围内缺失凭证，完成后清除；整书重提和章节回收在待继续期间禁用。检查 E12、E13。

## 2. 清空与关联维护

- [x] 2.1 生命周期映射改为删除状态：受影响映射 `state='deleted'`、去掉 `currentId`、保留 `originId`；不得删除其他章节成功凭证依赖的映射。检查 E06。
- [x] 2.2 整书世界清空：删除人物、地点、关系事实、关系编辑、迁移归档和世界凭证；节点移除已删人物编号并保留称呼；清除 P2，P3 标记失效。检查 E01、E08。
- [x] 2.3 单章世界清空：按 `originIds` 删除本章人物地点；清理承载关系和涉及已删编号的人物对编辑；保留关系重新收敛目标；其他章节凭证保留；人物和地点编号都失效相关 P2/P3。检查 E03、E06。
- [x] 2.4 整书叙事清空：删除节点、事件线和 P3 结果；节点/事件线生命周期改为 `deleted`；人物地点关系保留。检查 E02。
- [x] 2.5 单章叙事清空：按 `originIds` 删除节点；事件线移除节点，空线删除并改生命周期；保留线更新成员和修订号；失效 P3。检查 E03。
- [x] 2.6 新资产写入后按现有 `remapCharacterLinks` 和 `syncRelations` 重新绑定节点称呼和关系目标。检查 E01、E03。

## 3. 失败与恢复

- [x] 3.1 清空后模型失败：保留已完成的新资产/凭证和 `reExtract`；主按钮显示继续重提；刷新/取消后范围保留。检查 E12、E13。
- [x] 3.2 清空后首章失败立即导出：确保其他章节凭证、关系端点、节点关联、事件线和生命周期通过备份校验；恢复副本可继续提取。检查 E07。
- [x] 3.3 重提同时持有 extraction 与目标域租约；调整 `checkLease` 允许同一 owner/runId 的目标域租约，其他任务仍拒绝。检查并发和取消。

## 4. 界面

- [x] 4.1 `ExtractionPanel` 标题区增加“重新提取世界资产”“重新提取叙事资产”；按成功凭证、待继续重提、运行状态和恢复状态启用/禁用。检查 E09、E11。
- [x] 4.2 整书重提确认框显示范围、清空数量、下游影响和阻断原因；取消不发请求。检查 E10。
- [x] 4.3 `ChapterBrowser` 在成功状态旁增加回收图标按钮，点击直接重提，不弹确认；运行中或存在待继续重提时禁用。检查 E03、E11。
- [x] 4.4 存在 `reExtract` 时主按钮显示“继续重提世界资产/叙事资产”，并显示当前章节、步骤、请求次数和整体进度。

## 5. 测试与交付

- [x] 5.1 单元测试：整书/单章世界与叙事清空重提、合并后单章清空和其他凭证仍有效、节点/关系/事件线清理、失败继续、取消/刷新、租约冲突、P2/P3 失效。
- [x] 5.2 备份测试：清空后首章失败立即导出并恢复；恢复后继续重提；不出现悬空人物、关系端点或生命周期目标。
- [ ] 5.3 浏览器测试：两个整书按钮、整书确认框、章节回收按钮无确认、继续重提入口、运行中禁用、刷新后范围保留、失败提示。
- [x] 5.4 回归普通 P1 开始/继续/失败补提取、P2/P3 启动门槛、备份恢复和资产编辑锁。
- [x] 5.5 运行 `npm run typecheck`、`npm run lint`、`npm run test`、`npm run test:workspace`、`npm run build`、`npm run governance:check`、OpenSpec 严格校验，记录命令和结果。
- [ ] 5.6 在短样本或副本上用真实模型执行整书/单章重提，记录新格式、费用、耗时和失败恢复；用户确认后再对原书执行。
- [ ] 5.7 用户验收后同步提取主规格、界面规格、操作契约和资源归属，再归档本变更。

## 验收场景

| 编号 | 前置与样本 | 操作 | 预期结果 | 失败/恢复检查 |
|---|---|---|---|---|
| E01 | P1 完成，世界资产有凭证 | 整书重提世界资产并确认 | 旧世界资产和P2结果清空；逐章重建；节点保留并重新绑定；P3进度失效 | 失败保留新章节和继续入口 |
| E02 | P1 完成，叙事资产有凭证 | 整书重提叙事资产并确认 | 旧节点、事件线和P3结果清空；逐章重建节点；人物地点保留 | 失败保留新章节和继续入口 |
| E03 | 第12章两类成功 | 点击第12章世界/叙事回收按钮 | 不弹确认，直接清空并重提第12章；其他章节不变 | 失败可继续 |
| E04 | 多章样本，注入一章模型失败 | 整书重提 | 已完成章节保存，失败章节显示原因 | 旧资产不恢复；主按钮继续重提 |
| E05 | 重提运行中 | 取消或刷新 | 已保存的新资产和凭证保留；`reExtract`保留 | 不自动恢复旧数据 |
| E06 | 第1章人物已合并到第2章编号 | 点击第2章世界回收 | 第2章编号和第1章映射改为deleted；第1章凭证仍有效；新人物不继承其他章节事实 | 其他章节资产保留 |
| E07 | 清空后首章请求失败 | 立即导出并恢复 | 备份校验通过；无悬空人物、关系端点、生命周期目标 | 恢复后继续重提 |
| E08 | 有P2队列、合并和P3事件线 | 世界重提成功 | P2旧编号结果清除；P3进度失效；事件线保留 | 旧报告不当作当前结果 |
| E09 | 无成功凭证、模型未配置或待继续重提 | 查看或调用重提 | 按钮禁用或请求拒绝 | 旧数据不变 |
| E10 | 点击整书按钮 | 确认框取消 | 不清空、不发请求 | 按钮恢复 |
| E11 | 提取运行中 | 查看重提入口 | 整书和单章按钮均禁用 | 不并发启动 |
| E12 | 整书重提首章失败 | 点击继续重提 | 只补世界或叙事缺失章节；不重新清空；不转到普通两种步骤 | 完成后清除`reExtract` |
| E13 | 单章重提第12章叙事中刷新 | 重新进入 | 仍显示第12章叙事继续入口；范围不丢失 | 不重新清空 |
| E14 | 重提成功后刷新/导出恢复 | 刷新或备份恢复 | 新资产、凭证、进度和`reExtract`状态一致 | 恢复后不自动运行模型 |
