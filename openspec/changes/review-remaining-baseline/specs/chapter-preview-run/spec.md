# 单章试跑

## Purpose
让用户在正式保存资产之前查看一章小说的模型提取结果、失败原因和费用信息。试跑复用正式模型与提取契约，并明确与正式资产保存的区别，使用户能够核对效果后再决定执行正式提取。

## ADDED Requirements

### Requirement: TRIAL-01 查看单章结果
系统 SHALL 对首章执行世界资产和叙事资产试跑，展示原文片段、人物、地点、节点、耗时、用量及各子步骤失败原因，支持重跑。

#### Scenario: 部分结果和失败反馈
- **WHEN** 世界资产试跑成功而叙事试跑失败
- **THEN** 展示成功内容和具体失败子步骤及原因，用户可重新试跑。

### Requirement: TRIAL-02 正式资料保持不变
系统 SHALL 将试跑结果用于预览，保持本书当前资产、提取成功凭证及正式进度不变。

#### Scenario: 试跑结束后刷新
- **WHEN** 对已有资产书籍试跑并关闭结果，再刷新
- **THEN** 正式资产及进度与试跑前一致；试跑成功不解锁正式全书完成条件。
