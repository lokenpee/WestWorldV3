# 免密钥模型服务

## Purpose
根据模型适配器的鉴权能力区分需要密钥和无需密钥的服务，使配置、按钮状态、模型调用及错误反馈保持一致。无鉴权服务仍使用统一模型入口和同样的取消、校验与用量反馈，方便本地或其他明确支持的端点接入。

## ADDED Requirements

### Requirement: AUTH-01 按服务声明鉴权
系统 SHALL 按适配器的凭据要求决定调用条件，需要密钥的服务检查已保存凭据，无需密钥的服务按其声明直接调用。

#### Scenario: 无鉴权服务测试
- **WHEN** 选择明确声明无需密钥的受支持适配器，保存有效地址和模型后测试
- **THEN** 可通过统一模型入口完成生成；配置和提示不要求伪造密钥。

#### Scenario: 需要鉴权的服务缺少密钥
- **WHEN** 选择需要密钥的适配器且没有保存凭据
- **THEN** 显示填写凭据提示，保持其他资料不变。
