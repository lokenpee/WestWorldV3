### 后端字段和 SQLite 复查

SQLite 在通用记录的 JSON 正文保存人物、地点和节点字段。精简字段使用兼容的读取与备份结构，无需改表或迁移旧书。用隔离 SQLite 库跑 P1，再用另一个数据库连接直接核对磁盘记录，确认新行可省略旧字段、旧行保留数字年龄和节点对象、新线索可编辑保存。通过书籍备份服务将同一本书恢复到副本，核对新旧资料和关系标签。

复查发现旧节点合并命令只继承保留节点的线索，现已合并各成员的线索并去重。后端专项 79 项、SQLite 套件 97 项通过，SQLite 套件另有 5 项按既有配置排除。类型与 OpenSpec 校验通过。

## 用户验收

在小说副本中提取有待查证线索和日常情节的章节，再刷新打开节点详情。核对涉及人物的范围、可查证线索及原文依据、日常节点无线索、转述的新增事实和已实际发生的状态变化。核对人物、关系、地点的可选信息是否按原文证据填写。保存节点，导出备份并恢复到独立副本，核对线索与原内容。打开已有人物和节点核对旧年龄回显、人物关系及旧对象。

在有编号缺口的小说副本选择单章叙事重提，核对该章新提取结果从 `N001` 排列、旧归属解除和其他章节保留。固定模型响应已验证单章及全书重提、被复用编号的版本更新、跨章旧事件只移除该章节点和备份校验。[重提检查](../../../tests/extraction.test.ts)
