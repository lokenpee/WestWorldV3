# REQ-033 精简 P1 提取字段

## Why

用户审查 P1 字段后要求删除模型置信度、重复的关系方向和年龄数字、事件节点的对象与开始行动字段，并要求界面、存储、旧书及备份继续可用。

## What Changes

新提取用一个年龄文本和一个涉及人物列表。事件节点新增可选线索，补充新增事实和状态变化的提取口径。已有 P3 后续另行调整。

## Capabilities

### Modified Capabilities

- `extraction` 精简提交字段，补充事件线索和兼容规则。

## 确认依据

2026-11-20，用户要求先推送现有版本，再按讨论执行字段调整，明确要求本次直接去掉 `started_actions` 的新提取，P3 后续另改。旧字段兼容性覆盖前端、后端、底层数据及相关代码。基线为 `98ea647`，已推送到 `origin/codex/core-upload`。

用户随后要求优化全部 P1 提取提示词，明确必填、选填和长度，并补充少样本示例。长度用于约束模型写作，沿用已确认的提交校验与兼容规则；节点线索先按具体查证对象收窄。
