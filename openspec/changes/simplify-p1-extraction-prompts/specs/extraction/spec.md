## ADDED Requirements

### Requirement: P1-PROMPT-01 提取提示词与工具职责
系统 SHALL 将 P1 世界资产与叙事事件提示词组织为任务、铁律、字段和工具四部分；字段正文说明业务含义，结构约束由工具 Schema 提供。保留关系依据及方向、人物指向、完整事件粒度和传闻来源要求，删除 ID 分配、重复结构、自检及程序内部说明。

#### Scenario: 两类提取请求
- **WHEN** 执行世界资产或叙事事件提取
- **THEN** 分别发送对应业务提示词和唯一 submit_result 工具；世界资产保留已确认外貌说明，叙事事件按完整事件提取，关系证据不足时省略关系而非填“未知”；公共文学资料说明仍在 system 末尾。

### Requirement: P1-INPUT-01 纯净章节消息
系统 SHALL 以章节名称、两个换行和原始正文组成 P1 的初始 user 消息，章节编号等元数据留在程序内部。

#### Scenario: 发送与保存
- **WHEN** 两条 P1 子步骤处理标题为“码头”、正文为“沈青收到来信。”的第1章
- **THEN** user 内容为“码头\n\n沈青收到来信。”，保存结果及成功凭证仍关联第1章。

#### Scenario: 无效结果修正
- **WHEN** 模型返回无效提取结果触发修正
- **THEN** 原始章节消息保持不变，工具错误和修正要求作为独立后续消息发送；修正成功后沿原事务保存一次。
